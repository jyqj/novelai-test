## 一、书名与简介工程

**适用场景**：P1 蓝图定稿前的开书包装工序（P1 situational route=web 白名单已含本块）；diagnose「开书包装（书名/简介）不过关」。

**输入**：`Blueprint.high_concept`（一句话卖点）、类型定位、element_seeds 中的核心爽点元素。

### 1.1 书名组合律

书名 = **类型词**（流派信号：修仙、神豪、求生、领主、克系……）＋ **爽点词**（核心爽感：无敌、签到、苟、满级……）＋ **差异词**（专属记忆点：反差或具体意象）。三类不必齐备，判定下限：**≤12 字、含类型信号、含 ≥1 个差异记忆点**。产出候选 3–5 个（对齐 Blueprint `title_candidates ≥3`），每个候选标注三词拆解。

### 1.2 书名禁忌（三条，命中即弃）

| 禁忌 | 判定 |
|------|------|
| 生僻字 | 用字超出常用 3500 字表 = 弃 |
| 无类型信号 | 遮住分类与简介，从书名读不出品类 = 弃 |
| 撞名 | 与知名热书全名相同或仅一字之差 = 弃；候选逐个做站内＋全网检索（有本地书名语料则 rg 比对） |

### 1.3 简介三段式（全文 ≤200 字）

| 段 | 内容 | 配额 |
|----|------|------|
| 人设钩 | 主角是谁＋一个反差或异常处境 | 1 句 |
| 冲突钩 | 他面对什么、赌注是什么 | 1–2 句 |
| 爽点承诺 | 读者将看到哪一型爽（复仇、扮猪吃虎、经营……） | 1 句 |

**末句必须给期待**（悬念问句或宣言句）。禁忌：世界观名词倾倒（简介内新专名 ≤3）、人名 ≤2 个、全文无一句主角目标 = FAIL。

### 1.4 首屏 300 字自检（对接 K-CONCEPT-020 第二道门）

① 主角在场且有动作；② 出现 ≥1 个反常/悬念信号；③ 新专名 ≤2；④ 气质与简介承诺一致（简介卖爽而首屏阴郁压抑 = 预期错位）。四项全过才算包装闭环——书名简介引进来的读者，首屏必须接得住。

### 1.5 操作步骤与可判定标准

1. 从 high_concept 与类型定位提取三词候选池，组合 3–5 个书名候选。
2. 每个候选过 1.2 三禁忌，全灭则回炉候选池。
3. 按 1.3 写 blurb_draft：数句子、数字数、数专名与人名。
4. 首屏 300 字成文后跑 1.4 四项。
5. 结果写入 `Blueprint.title_candidates[]` / `blurb_draft`。

| 检查项 | 通过判据 |
|--------|----------|
| 候选量 | title_candidates ≥3，均 ≤12 字且过三禁忌 |
| 简介 | ≤200 字、三段齐备、末句给期待、专名 ≤3、人名 ≤2 |
| 首屏 | 1.4 四项全过 |

### 1.6 示例

《我师兄实在太稳健了》十字：「师兄」是类型词（修仙门派文），「稳健」兼差异词与爽点信号（苟流），书名即人设即卖点。《全职高手》四字：「全职」类型词（电竞职业）＋「高手」爽点承诺。反例参考：《庆余年》类型信号弱，靠内容与推荐位扛起——名书不等于可复制的开书策略，新书默认走组合律。简介示范（三段式，52 字）：「大理寺最年轻的验尸官，穿成待嫁废柴（人设钩）。退婚夜，她验出未婚夫杀人的铁证（冲突钩）。从今天起，京城的案子她说了算（爽点承诺＋宣言收尾）。」

## 二、主角讨喜度与代入感工程

**适用场景**：P1 主角种子设计（situational `protagonist_design` 白名单已含本块）；P2 人物骨架与 P4 Character 建卡（P4 `char_canonize` 白名单组尾）；P6 critic 轮抽检讨嫌判据；diagnose「主角讨嫌/代入感差」。

**输入**：`Blueprint.cast_seeds`（protagonist 条目）、类型定位、金手指或核心优势设定（element_seeds / WorldRule 草案）。

### 2.1 视角与称谓选择表

| 选项 | 代入强度 | 适用 | 纪律 |
|------|----------|------|------|
| 第三人称限知单视角 | 高（网文默认） | 绝大多数品类 | 前 10 章主角视角占比 100%（引子章除外） |
| 第一人称 | 最高，但品类窄 | 克系独白、无限流、轻小说 | 主角不可长期离场；他线信息须借转述或道具 |
| 多视角群像 | 中 | 群像史诗 | 主角戏份 ≥60%；卷一不建议开多视角 |

称谓纪律：主角名 2–3 字、无生僻字（3500 常用字表内）；同卷高频出场角色的姓名首字互不重复（防脸盲，与 K-CHAR-013 声纹区分度同向）。

### 2.2 道德底线红线（三条）

1. **不圣母**：判据见《06-内容安全与边界》第二章圣母行——为陌生人牺牲核心利益且无补偿 = 违规。
2. **不窝囊**：被动挨打（章内只承受、无任何反制动作——还手、布局、立誓、取证均算反制）**≤1 章**。此线比憋屈红线（≤2 章）更紧：憋屈可以发生在反制过程中，纯挨打不行。
3. **恩怨必偿**：恩情与仇怨一律登记（Thread 或 payoff 台账），仇怨在 ≤1 卷内给出偿还动作或明示时间表；恩情同规。

### 2.3 金手指亮相纪律

**≤第 2 章完成首次亮相**：读者可感知其存在，且首层功能生效一次、有可见后果；全貌可后置分层揭示（对接 K-WORLD-024 三段曲线的前期段）。无金手指品类（历史、谋略流）以核心优势能力替代，同窗口亮相。判定：第 1–2 章内存在金手指/核心优势的首次生效场景。

### 2.4 人设记忆点预设计

开书前预设三件并写入 `Character.voice`（对接 K-CHAR-013 声纹五件）：口癖 ≤3、标志动作 1–2、**名场面坑位 ≥2**——该人设最出彩的场景类型（如"谨慎人设被迫冒险时的破例爆发"），排入前 10 章与卷一高潮的章纲意图。

### 2.5 讨嫌判据清单（四项，critic 轮抽检）

| 讨嫌项 | 判定 |
|--------|------|
| 说教 | 主角向他人单向输出价值观且无人反驳，单次 ≥半页或单章 ≥2 次（病因见 K-CONCEPT-016） |
| 自怜 | 同一自怨主题的内心独白单章连续 ≥3 段，或跨 ≥2 章重复 |
| 被动挨打 | 超 1 章（判据见 2.2） |
| 无理由圣母 | 圣母判据命中且无补偿爽点 |

### 2.6 可判定标准

| 检查项 | 通过判据 |
|--------|----------|
| 视角纪律 | 前 10 章视角合规；称谓过字表与首字查重 |
| 金手指窗口 | 第 1–2 章有首次生效场景 |
| 记忆点落卡 | voice 含口癖/标志动作；名场面坑位 ≥2 且已排章 |
| 讨嫌扫描 | 四项全"否" |
| 恩怨台账 | 仇怨与恩情均有登记及偿还章号（或时间表） |

### 2.7 示例

韩立（《凡人修仙传》）：「谨慎」是单词级人设记忆点贯穿全书；恩怨分明——墨大夫之害必偿、对有恩者必报，是恩怨必偿的范本；金手指小瓶开篇数章内亮相生效，全貌吊了数百章。李长寿（《我师兄实在太稳健了》）：「稳」字人设直接进书名，名场面坑位即"稳健人设被迫出手时的反差爆发"——记忆点预设计与开书包装（第一章）联动的示范。
