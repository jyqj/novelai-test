# 连续性：事实、因果、知情与人的经验

## 1. 两种状态，不能混成一份摘要

故事状态：世界实际怎样、谁在哪里、持有什么、事件的前提与后果、人物相信什么、未出场者在做什么。

读者状态：已经展示什么、当时自然可推断什么、最可能误解什么、在等待什么、为何在乎、哪些旧信息需要自然重锚。

“读者会这样想”是编辑假说，不是客观事实；冷读结果单独记录样本与阅读截止点。计划中的反转不能进入读者模型当成已经理解的事实。

## 2. 每次重要选择保留一条因果记录

事件/场景 → 前提事实与原文章号 → 行动者的目标、信念与可选策略 → 实际选择 → 结果与成本 → 谁受影响 → 尚待发生的后果。

这是一张可以分叉、汇合的图，不强制每场只由上一场引发。依赖必须有类别：促成、阻止、获知、改变关系、主题呼应。主题呼应不能当作物理因果；相关不能冒充促成。

删除一个场景后，分别检查事件链、读者理解、情绪积累、承诺体验是否受损。陪伴、幽默、日常、哀悼和世界质感可以独立贡献，不能因不输送资源给主线就删掉。

## 3. 真相、说法、信念分开

记录“甲说 P”并不确认 P；“乙相信 P”不意味着乙知道真相。对关键误信记来源、获知场景、确信程度（文字描述即可）、哪些反证会改变他。允许怀疑、遗忘和自欺，但要有文本基础。

组织成员关系不是自动知情权限。授予知识应记录发生时刻与实际传播对象；新成员不自动知道旧秘密，离开组织也不自动失忆。既有 knowledge grant --ch 与历史查询负责已实现的获知记录；复杂信念与二阶猜测在实体/叙事记忆中维护，不声称工具已自动推理。

## 4. 人物变化要有过渡

稳定设定写欲望、恐惧、价值冲突与常用策略；当前状态写受何事件影响、如何理解对方、当前能说/不能说什么、接下来可能选择什么。成长可以是认识变化、坚守的代价或关系边界变化，不要求每卷人格重生。

声纹是注意力、判断习惯、社会位置与对话策略，不只是三句口癖。受众、情境和亲密程度可以改变说法。不要通过不许改变句长来维持人物一致。

## 5. 任务驱动的记忆召回

先问本场景需要哪些证据，再找来源：决策依据、旧承诺原话、关系受伤的场面、将回收的具体细节、离场角色的实际影响。重要性与距离分开；远期伏笔回收时应取回原文，而不是继续压缩。

现有 task 的 context_entities、fact_refs、memory_refs、memory_keywords 用于检索；明确依赖写引用，不只写“请记住前文”。narrative_memory.evidence 逐字指向已写正文，解释与证据分开。已闭合线索仍可因后果或呼应被明确召回，不能因为 paid_off 就视为从未存在。

默认召回先按 memory_keywords 与 threads/context_threads 的命中数，再按人物相关与时间排序；六条是非强制记忆组的上下文预算，不是叙事容量定律。工具只做显式标签匹配，不理解“和解为什么需要这段历史”。资料员先提出历史问题，查支持、反证、后文修正，再将关键词、线索或确切引用交给编译器。

### 解释会变，经历不删除

“她拒绝帮助”是事件；“我以为她不信任我”是当时的理解；“后来发现她担心转嫁风险”是新理解。后两者不应覆盖第一项，也不应互相冒充当下真值。

后文记忆可写 `reinterprets: ["ch_0001#0"]`，引用更早章节 narrative_memory 的零基序号。text 说明谁改变了何种理解、还不能推出什么；evidence 仍须是本章原文。此链接是编辑申报，程序不裁定解释正确。召回任一端时，同一历史截止点内的解释链整体进入同一预算条目；明确依赖则整组保留，否则整组可裁。不会读取未来修正，不删除旧记录或改变角色知情。

旧记忆没有链接时保持原行为。返修旧章若重排/删除记忆数组，须人工核对全部引用；编号不是跨修订稳定 ID，程序只能发现不存在的引用，不能证明同一序号仍是同一语义。复杂遗忘、二阶信念和自动反证检索仍由编辑负责。

本轮新增 task.creative_brief 只传本章的人工策划说明：情绪来处、读者当前位置、允许发挥范围、所用方法。它不替代 canon，不用于塞入未经批准的新事实，不自动提取信念或阅读反应。

## 6. 修订向后传播

修改旧事实/获知/关键选择时，列出依赖它的后续场景、关系、伏笔和读者误解。不是只更新人物“现状”即可。已发布稿遵循现有版本与 retcon 约定；在影响消化前标注不确定，不让摘要替正文默默圆谎。


`context_threads` 可列仅供历史/后果参考的 thread id，不向终态线发送推进 op。简报按目标章历史状态召回，并将选中线的“回收设计”单列为编辑计划，不能当成已发生真相；现有依赖哈希与预算纪律仍适用。
