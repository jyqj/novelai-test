# 定式是有条件的功能模式，不是统一剧情表

## 1. 先拆维度

| 维度 | 可选择的组织方式 | 现有兼容入口 |
|---|---|---|
| 整体戏剧弧 | 三幕/阶段转变/探索式/成长或坚守 | classic24 是其中一个参考 |
| 情绪与兑现 | 波浪、持续安静积累、喜剧复现、紧张延续 | wave |
| 局部活动 | 调查、闯关、比赛、谈判、救援、生活事务 | dungeon 属活动/资源框架 |
| 单元组织 | 单元闭环、连续大事件、混合 | episodic |
| 视角分配 | 单视角、多焦点、群像汇聚 | ensemble |

它们可以组合，不是五选一。arc 保留“模板”字段作为兼容主标签，旁边写模式组合与取舍；工具不会替作者自动解决组合冲突。场景、事件、章节、弧不是固定同构单位，一场可以跨章，一章可以承载多个场景。

## 2. 六张起步模式卡

### 调查揭示

适用问题：希望读者参与解释与修正。前提：可观察证据与角色推断渠道。功能：异常 → 可置信解释 → 据此行动 → 矛盾/代价 → 重释证据 → 改变选择。可变：真相已对读者公开、调查者失败、局部正确而整体错。失败：藏掉必要信息、靠新规则翻盘、每次只是换嫌疑人。无需每个单元都反转。

### 能力成长

适用问题：让读者体验掌握和运用。前提：清楚不足与反馈。功能：不足 → 选择路径 → 尝试/反馈 → 理解或运用变化 → 在重要场合证明 → 处境变化。可变：坚守旧技、团队协作、失败后改变目标。失败：训练与解法无关、数值升级而问题不变。无敌主角可改为探索运用与责任，不伪造战力不足。

### 关系重构

适用问题：让亲近、疏离或信任变化可信。前提：原有相处方式及各自需求。功能：旧平衡 → 不同诉求 → 付出/拒绝/误解 → 判断变化 → 边界重定。可变：没有和解、明白但不能同行、亲密中保持分歧。失败：一句表白跳过旧伤、用事件奖励强行买来信任。

### 团队行动

适用问题：让协作与分歧共同驱动行动。前提：目标、不同动机、实际分工。功能：计划 → 接触现实 → 局部失效或机会 → 各人选择 → 结果 → 团队关系/资源重排。可变：计划有效也有戏，戏剧性可来自执行与情感，不强制失败。失败：队友只负责赞美、完美备选计划凭空出现。

### 日常余波

适用问题：积累陪伴、质感、理解或消化大事件。前提：人物有具体小愿望和生活处境。功能：事务/愿望 → 摩擦或细节 → 新侧面 → 满足/遗憾 → 情感余波。可变：轻喜剧、安静哀悼、习惯变化。失败：只复述已知感情、装饰细节与体验无关。无需新增主线危机才有资格存在。

### 长程收束

适用问题：结束扩张并兑现核心承诺。前提：知道哪些承诺已公开及其依赖。功能：盘点 → 让分散后果汇合 → 关键选择 → 兑现/有意识的开放 → 生活与关系的余波。可变：多高潮、安静收尾、部分问题不可解。失败：最后再开更大的 Boss 逃避回答；把每个普通细节都强拉回收。

## 3. 使用步骤

先写本段希望产生的体验与现状限制；提出几条由人物动机自然产生的路径；选能帮助解决问题的模式；写清哪些功能使用、哪些不用及理由；正向检查角色是否会这样选择；再安排读者看到信息的顺序。用原文冷读检验，不以节点齐全代替有效。

同一模式可以重复。比较的是因果与情感结构：谁拥有优势、谁误信、采用什么策略、谁承担代价、关系与问题怎样变化。仅换地图不算变奏；同一场景形式承载相反意义可以是重要呼应。不设置“同套路全书仅两次”。

组合时只保留少量明确有用的维度。例如：episodic 的局部结案 + ensemble 的信息差 + 日常余波收尾；结案不要求关系归零，切视角不允许无限延期热门线的承诺。模式之间冲突时以本书体验、事实和人物选择为先，不把所有检查项取并集。

## 4. 从作品学习模式

在阅读截止处先记实际可见证据、期待与误解，再阅读后续并对照；避免事后把全部细节解释成作者早已计划。记录失败和反例、类型/章长/连读或追更场景。按 templates/pattern-card.md 存“机制＋条件＋变奏＋反例”，不保存可换名复用的具体名场面。
