# 原文召回使用说明

当旧事件要影响当前选择、回收或关系时，在章任务中增加可选 `evidence_refs`。它补足摘要与叙事记忆，不自动建因果图、判定真相或授予角色知识。

```json
{
  "evidence_refs": [
    {
      "chapter": "ch_0001",
      "quote": "门簿上记的是铜铃，不是人。",
      "purpose": "核查旧记录实际能证明什么",
      "context_chars": 180
    }
  ]
}
```

chapter、quote 必填；其余选填。chapter 沿用现有四位章号，必须早于目标章；quote 在实际正文中逐字匹配，不在标题、元数据或作者笔记中找。来源允许 drafted/approved/published，简报会标注状态；工作坊试写不作为正史引用。

同一句出现多次时补 `occurrence`（从 1 计），避免选错场景；不填写时只有唯一匹配才使用。context_chars 是两侧各取多少字符，默认 180、范围 0–2000；这是摘录预算，不是文学规则。需要更完整语境时引用一段完整文本并在总简报预算内安排。

引文与附近文本进入简报 §2，带真实文件路径、行范围、来源状态和“文字不自动等于真相”的标记。purpose 是编辑选取说明，不是事实。源码在 tools/novel_lib/evidence.py。

明确依赖不会因预算不足静默丢弃。来源缺失、原句已被修掉或必要材料超预算时，保留上版简报并报告；修任务、缩小无关材料或调整预算后重编。源正文即使只改周围语境，也会使依赖清单失效，避免继续使用旧解释。

没有 evidence_refs 的旧任务照常工作。它不是自动全文检索器：先由资料员找到需要的章和原句，再声明依赖；若只知道大概发生过什么，先用摘要与线索导航，不编造一条“可能的原话”。原文可含传言、谎言、误信或不可靠叙述，知情与真值仍须单独判断。
