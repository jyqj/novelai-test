# mode-solo — 单代理降级模式（帽子切换）

适用：产品**不能 spawn 子代理**。同一个 agent 顺序扮演编排者/写手/评审，用「帽子协议」
模拟多代理产线的信息沙箱与对抗评审。协议与文件契约不变（仍读 `protocol/`、仍走
`novel.py` 闸门），变的只是「谁来干」。

## 1. 帽子协议（核心纪律）

1. **一次只戴一顶帽子**。戴帽前显式声明：`【戴帽:写手】输入=briefs/ch_0012.brief.md`。
   收工时产物**先落盘/写出**，再摘帽。禁止在一段回复里混两顶帽子的工作。
2. **帽内输入白名单**：每顶帽子只允许使用其声明的输入。写手帽 = 简报全文，**不得**回看
   tree/、entities/ 原文（简报没有的信息就是没有——缺料写进 issues，不脑补）；
   评审帽 = 产物 + 对应 rubric 卡 + 简报，**不得**引用「我写作时本来想…」的意图为作品辩护。
3. **产物间隔离靠自查**：摘帽前跑泄漏自查（`SKILL.md` §5.3）——产物里出现简报之外的
   专名/设定即违规，删除或补录简报来源后重交。
4. **顺序固定**：编排者（排批/装简报）→ 写手 → 机检（CLI）→ 轻评 → 编排者（commit/裁决）。
   帽子顺序不可跳；机检永远在轻评之前（免得评审给不合格产物找补）。

## 2. 单章循环（solo 版）

```
【编排者】task next → task start → brief ch_NNNN
【写手】  只读简报 → 产出 候选章.md + writeback.json（回应契约=简报 §8）
【CLI】   check --unit … --candidate … --writeback …   # FAIL → 写手帽返修（≤2 次）
【轻评】  戴 critic-light 帽：按卡逐项过 + 裁定机检 NEEDS_REVIEW 项 → verdict
【编排者】pass → commit → task done → set-status approved
          revise → 带问题清单回写手帽（pipeline §2 修订循环同样适用）
```

节流默认：每章 1 轮轻评 + ≤2 次返修；深评每 `deep_every` 章一次。

## 3. 庭审降级（设计庭 solo 版）

多提案对抗降级为「**1 提案 + 判据自评 + 抽人设卡**」三件套：

1. **1 提案**：戴 Architect 帽按 court §2 该场次的产出契约写提案；写完**必须**附
   「自我攻击」节：列出本提案最可能被否的 3 个理由（强制对抗，防自我满意）。
2. **判据自评**：戴 structure-critic / safety-auditor 帽，逐条过 `rubrics/structure.md`
   与 `rubrics/redline.md`（书庭另加 `rubrics/toxicity.md`），每条写 PASS/FAIL+一句证据。
   红线命中 → 一票升级，直接上报用户，不得自我豁免。
3. **抽人设卡**：从 `personas/` 随机抽 2 张（书庭 3 张），逐张以该人设第一人称回答：
   「我会为这个设定付费追更吗？弃书点在哪？」——投票与毒点照卡上纪律执行。
4. 裁决照常写 `dec_*.md`（含否决案 + reopen_requires），照常走
   `commit --file`。**solo 不豁免任何落盘要求**，否决案台账在 solo 模式尤其重要
   ——它是你唯一的「另一个大脑」。

## 4. 沙箱模拟与"隔日重读"

- 无法物理隔离信息时，用**时间隔离**替代：深评（critic-deep 帽）安排在新会话/新上下文里做,
  开工输入只给「章文本 + rubric + 简报」，明令禁止先读自己的 writeback 与轻评单。
- 每卷至少一次「冷读」：戴 reader 帽 + 随机人设卡，从卷首连读 3 章，只报弃书点。

## 5. solo 特有风险与对策

| 风险 | 对策 |
|---|---|
| 自我评审放水 | 机检先行（不可协商）；评审帽输出必须逐条引 rubric 编号；verdict=pass 但未过条目 → 无效 |
| 上下文污染（写手记得设定原文） | 泄漏自查以简报为唯一基准；发现引用简报外事实按泄漏处理 |
| 长会话遗忘 | 一切进度以 `status`/`task next` 为准；会话开头永远先跑 status，禁止凭记忆续写 |
| 无人对抗导致设定平庸 | 提案强制「自我攻击」节 + 人设卡毒点问答；书/卷级裁决尽量呈报用户 |
