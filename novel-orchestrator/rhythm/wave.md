# 节奏模板 · wave(网文标准波浪 · 默认)

## 适用

- 题材:升级流/都市/玄幻/仙侠等主流男女频长连载;无特殊结构需求时的**默认模板**
- 体量:弧 8–25 章(含 1–3 个波),卷 80–250 章;全程可持续复用
- 场景:需要稳定追读节奏、以"小高潮循环 + 卷末大高潮"运营的连载

## 结构段落

一个**波** = 铺垫→升级→小高潮→回落;弧 = 1–3 波;卷末波放大为卷级大高潮。

| 段 | 占比(波内) | 职责 | 出口判据 |
|---|---|---|---|
| 铺垫 | 25–35% | 开新承诺、积压抑、亮对手与赌注 | 读者能一句话说出"这波在等什么" |
| 升级 | 30–40% | 三选一推进:加码/加险/加料;投入可见 | 赌注比铺垫段更大 |
| 小高潮 | 15–25% | 兑现:打脸/突破/揭示,伴随处境变化 | ≥1 条 payoff realized |
| 回落 | 10–15% | 结算收益、降档喘息、开出下波承诺 | 期待账户余额 ≥2 |

## 强制检查单

- [ ] 1. 每波有明确价值轴,一句话可概括"这波主角得到什么、付出什么"
- [ ] 2. **循环内价值递进**:本波波峰的处境/位阶/赌注高于上一波峰(禁平移循环)
- [ ] 3. 波峰含 ≥1 次处境级释放(upgrade/reveal/reversal 且伴随处境跃迁)
- [ ] 4. **回落章必含期待动作**:新承诺/升级/加料至少其一,禁纯日常章
- [ ] 5. 回落段期待账户余额 ≥2(未兑现且读者可感的承诺数)
- [ ] 6. 波内压抑段 ≤2 章,第 3 章有还手动作或明示还手时间表
- [ ] 7. 相邻两波峰间隔 ≤10 章;波长 >10 时波中部插一次中强度释放
- [ ] 8. 升级段投入可见(修炼/布局/资源消耗有记录),波峰兑现可指认压抑或投入来源(章号)
- [ ] 9. 同型爽点连续 ≤2 章(换型纪律)
- [ ] 10. **卷末处境跃迁**:卷末波峰=卷级 Boss 清算,位阶/地图/身份/关系至少一项不可逆变化
- [ ] 11. 卷末回落开出 ≥1 个指向新卷的承诺(与新卷引爆同源)
- [ ] 12. 新波首章承接上波结算余波或已开承诺,禁另起炉灶

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| wave_length | 6–12 章 | 波长;卷末波可 1.5× |
| waves_per_arc | 1–3 | 弧内波数 |
| cooldown_chapters | 1–2 章 | 回落段章数上限 |
| suppression_window | ≤2 章 | 压抑段窗口 |
| peak_interval | ≤10 章 | 相邻波峰最大间隔 |

## 与爽点窗口的关系

- 铺垫段:3 章窗口靠小爽(dopamine/humor/emotion)维持;开承诺本身计期待动作,不抵爽点配额
- 升级段:每章 ≥1 小爽 + 至少一次期待升级动作(加码/加险/加料)
- 波峰:大爽落位点;10 章 1 大爽由 peak_interval ≤10 直接保证
- 回落章:可豁免小爽(连续豁免 ≤1 章),但必含期待动作——这是"回落不断更"的生命线

## 常见崩法

1. **平移循环**:每波"遇敌→打赢→换地图"复读,价值不递进,50 章后套路疲劳弃读
2. **回落成假期**:回落章纯日常发糖,期待账户清零,追读理由消失
3. **波峰早泄**:铺垫不足两章就兑现,爽点无压抑来源=空转,读者无感
4. **无限爬升**:砍掉回落连续冲高,10 章后读者对刺激麻木,大爽贬值为日常
5. **卷末哑炮**:卷末波峰规模与日常波峰相同,处境无跃迁,翻卷即掉量
