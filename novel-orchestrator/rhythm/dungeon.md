# 节奏模板 · dungeon(副本秘境制)

## 适用

- 题材:副本/秘境/塔/遗迹/试炼结构;玄幻仙侠、游戏流、无限流的副本弧
- 体量:弧 = 一个副本,8–20 章;每卷 2–5 个副本,副本间插 1–3 章地面剧情
- 场景:需要强目标感、强结算感的闯关式篇章

## 结构段落

| 段 | 占比 | 职责 | 出口判据 |
|---|---|---|---|
| 进本前 | 10–15% | 亮承诺:奖励/风险/时限三要素;组队与筹备 | 读者一句话说得出"进本图什么" |
| 入本 | 15–20% | 规则展示 + 首个下马威;资源起算 | 规则立完,此后不再新增 |
| 本内推进 | 40–50% | 分层闯关,难度收益同步递增,资源持续消耗 | 每层有增量,消耗有记录 |
| 本内高潮 | 10–15% | Boss 战/核心机缘争夺,消耗此前积累 | 胜利成本可信 |
| 出本结算 | 10–15% | 收益清点公开化、挂回主线、开新钩 | 进本承诺逐条对账 |

## 强制检查单

- [ ] 1. **进本前承诺明确**:奖励/风险/时限三要素齐且具体(如"秘境三日后关闭,内有筑基机缘,往届死亡率三成")
- [ ] 2. 副本规则 ≤2 章内立完;此后禁止新增有利主角的规则(反转只能用已立规则的未用推论)
- [ ] 3. **资源消耗闭环**:入本携带清单化(药/符/底牌/人情/时限),本内消耗有记录,出本可对账
- [ ] 4. 分层递进:每层难度与收益同步递增,无平层刷怪段
- [ ] 5. 本内每 3 章 ≥1 小爽(层 Boss/夺宝/解谜/意外之喜)
- [ ] 6. 本内 ≥1 次预期外事件(他人搅局/规则反转/提前引爆),防流水账
- [ ] 7. Boss 战成本可信:胜利消耗 ≥ 本内积累的三成(无敌流豁免,改验"碾压的演出效果")
- [ ] 8. **出本结算爽点**:收益公开可见(位阶/装备/名声),且 1–2 章内给用武之地
- [ ] 9. 结算与进本承诺对账:奖励兑现或"变形兑现"并给解释,禁静默缩水
- [ ] 10. 副本收获挂回主线:≥1 条信息/仇敌/新地图指向本外剧情,禁副本孤岛
- [ ] 11. 同行者有功能分工与独立动机,无纯背景板队友
- [ ] 12. 设时限的副本:≥2 次时限逼近的决策点,时限压力全程可感

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| dungeon_chapters | 8–20 章 | 单副本章数 |
| pre_entry | 1–3 章 | 进本前铺垫 |
| layers | 3–7 | 副本层数/关数 |
| settlement | 1–2 章 | 结算章数 |
| dungeons_per_volume | 2–5 | 每卷副本数;连续副本间插 1–3 章地面剧情 |
| boss_cost_ratio | ≥30% | Boss 战消耗占本内积累比 |

## 与爽点窗口的关系

- 副本结构天然满足窗口:层 Boss/夺宝 = 3 章级小爽;出本结算 = 10 章级大爽(处境跃迁)
- 风险区在进本前铺垫:超过 3 章须插小爽(筹备中的意外收获/队内摩擦打脸)
- 地面剧情章按 wave 回落章纪律执行(必含期待动作,期待账户余额 ≥2)
- Boss 战章可多型叠加(upgrade+reveal+dopamine)但 ≤3 条,防稀释

## 常见崩法

1. **副本孤岛**:出本后收获与主线无关,10 章白玩,读者记不得为什么进本
2. **资源魔术**:消耗无记录,绝境凭空掏底牌,账对不上,爽点变尬点
3. **规则后门**:Boss 打不过临时加"隐藏规则",反转无预埋,读者按降智计
4. **平层刷怪**:各层难度雷同,中段沦为打怪流水账,完读率崩
5. **结算缩水**:进本吹天大机缘,出本给安慰奖,期待账户违约,下个副本没人跟着进
