# 节奏模板 · episodic(单元剧/无限流)

## 适用

- 题材:无限流/灵异怪谈/探案/快穿/委托制(镖局/佣兵/事务所)
- 体量:单元 5–12 章,弧 = 1–2 单元,每卷 8–15 单元
- 场景:以"一个个独立故事"为消费单位、主线暗线长程推进的连载

## 结构段落

| 段 | 占比(单元内) | 职责 | 出口判据 |
|---|---|---|---|
| 入局 | 15–20% | 立规则/谜面/委托,给出单元赌注 | ≤1 章内单元核心问题成立 |
| 展开与误导 | 35–45% | 调查/闯关,布设误导,险情递增 | ≥1 次误导已种下 |
| 真相与决战 | 20–30% | 反转揭底,解决单元核心问题 | 真相 ≠ 第一眼答案 |
| 结算与主线钩 | 10–15% | 收益结算 + 主线增量 + 下单元钩 | 主线增量可指认 |

## 强制检查单

- [ ] 1. **单元内闭环**:单元核心问题在本单元解决,无强制跨单元悬置(主线暗线除外)
- [ ] 2. 入局 ≤1 章:规则/谜面/委托与赌注立起,入局章末钩强制
- [ ] 3. 单元内 ≥1 次误导 + ≥1 次反转;真相回溯可信(关键线索此前已亮过)
- [ ] 4. **跨单元主线推进比**:每单元 ≥1 个主线增量(信息/道具/敌踪/伙伴变化),占单元篇幅 10–25%
- [ ] 5. 连续 3 单元的主线增量可连成可见递进链(拼起来是主线的一段运动)
- [ ] 6. 单元难度/规模跨单元递进,禁平位重复
- [ ] 7. 单元类型轮换:相邻 2 单元不用同型谜面(斗怪/斗人/解谜/生存/救援轮换)
- [ ] 8. 单元配角 ≤2 章立住动机;退场有交代(死亡/离队/入伙),禁用后蒸发
- [ ] 9. 每单元 ≥1 次处境级释放(大爽),落位在真相/决战段
- [ ] 10. 单元间衔接章 ≤1 章且含下单元钩子
- [ ] 11. 主角能力/心态/队伍跨单元有成长记账,禁单元间重置
- [ ] 12. 无限流:主空间/系统规则全书一致,单元内特例须可由主规则推导

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| unit_chapters | 5–12 章 | 单元章数 |
| mainline_ratio | 10–25% | 主线增量篇幅占比 |
| bridge_chapters | 0–1 章 | 单元间衔接章 |
| units_per_volume | 8–15 | 每卷单元数 |
| twist_count | 1–3 | 单元内反转数 |

## 与爽点窗口的关系

- 单元 ≤10 章时窗口自动满足:展开段的小胜/误导揭破/氛围钩 = 3 章小爽;真相/决战 = 大爽
- 单元 >10 章:展开段中部须插一次中强度揭示(半真相),防 10 章大爽窗口破
- 结算段可豁免小爽,但必含主线增量(等价期待动作)
- 单元开头 1–2 章是弃读高危位:入局章必须自带冲突,禁纯设定说明

## 常见崩法

1. **主线蒸发**:连续多单元零主线增量,读者忘记大目标,只剩单元消费,弃读随缘
2. **单元同质**:连续三个"进场→死人→找鬼→超度"复读,套路疲劳
3. **闭环破产**:单元真相靠下单元补,当期读感=烂尾,单元制的信任崩塌
4. **配角工具化**:单元配角无动机纯送死,emotion 爽点全空转,决战无重量
5. **难度跳水**:主角变强后单元威胁不升级,中期紧张感消失,变成日常文
