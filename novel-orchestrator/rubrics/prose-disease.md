# 判据卡 · AI 正文病(prose-disease)

> 自包含判据卡:LLM 生成正文的六类高发病及可判定阈值。适用对象:章级正文评审与交稿自查。判定顺序:先扫黑名单与硬阈值(可机械判),再做抽检类判定。项目 style.md 的禁忌清单效力高于本卡示例表,两表**并集**执行。

## 一、口癖与句式黑名单(命中即违规,无"偶尔可以"豁免)

典型 LLM 腔条目(15 条示例族,项目可按题材增删):

1. 嘴角勾起一抹(弧度/笑意/冷笑)
2. 眼底/眼中闪过一丝(……)
3. 眸中精光一闪
4. 不由得倒吸一口凉气
5. 空气仿佛凝固了
6. 心中暗道/心中一凛
7. 缓缓开口/缓缓说道
8. 深深地看了一眼
9. 声音很轻,却带着不容置疑的(……)
10. 一道(倩影/身影)闪过
11. 整个人如遭雷击
12. 仿佛要把人吸进去一般
13. 顿时/瞬间/霎时间——高频副词:单章合计 >3 次即违规
14. 值得一提的是/要知道/殊不知——说明文腔转场语
15. 这一夜注定(……)/谁也没想到(……)/而这一切,才刚刚开始——章末总结腔(判据见第四节)

新口癖判定:同一表述 3 章内重复 ≥3 次 = 新口癖,评审报告中应建议增补进黑名单。

## 二、句式多样性判据

| 检查项 | 判据 |
|--------|------|
| 同结构连用 | 连续 3 句同结构(同词性开头 + 同主干型)= 违规 |
| 段首重复 | 连续 3 段以同一人名/人称开头 = 违规 |
| 段尾情绪化 | 连续 3 段以感叹号或抒情短句收尾 = 违规 |
| 比喻复用 | 同一喻体全书累计 ≥3 次 = 超限,该喻体应入黑名单;单章同喻体 ≥2 次即预警 |

## 三、水字判据(命中任一即水)

| 类型 | 判据 |
|------|------|
| 复述已知 | 把读者已知信息换措辞再讲(回忆总结/角色间转述),且未附加新评价或新后果 |
| 无新值对话 | 一段对话结束时,信息、关系、情绪三者皆无变化(寒暄/车轱辘拉扯) |
| 静态描写超限 | 连续 >3 句无人物动作、与冲突无牵连的景物或设定描写 |
| 情绪同义反复 | 同一情绪用 ≥3 个同义句连续渲染(震惊了…不敢相信…难以置信…) |

**节奏底线**:每 500 字须有 ≥1 个新信息或价值变化(新事实/关系变动/处境变动/情绪转向,四者之一)。抽查法:任取一个 500 字窗口,问"读者读完这段比之前多知道/多感到了什么",答不出 = 水。

修法三选一(给建议时用):**删** / **并句压缩**(复述段压成一个从句挂在新动作上,如"想起昨夜种种,他攥紧了缰绳")/ **注入新值**(让一方带目的进场;静态设定改由动作与冲突承载,如护城河的宽度用一次失败的跳越写出)。

## 四、章末总结化

- 末段禁"总结/展望/感悟"句式:「这一夜注定…」「谁也没想到…」「而这一切,才刚刚开始」类。
- 末段只做局部收束:章尾钩句之前收束 **≤1 句**;多余的感悟段直接删。
- 章尾钩四型(悬念/危机/反转/期待)**同型连用 ≤2 章**。

## 五、关键场面概述化

- 本章高潮/对决场面**禁概述体**——不许"一番激斗,他险胜"式一段带过。
- 判据:该场面内对话+动作节拍合计占比 **≥60%**(概括叙述与心理总结合计 ≤40%)。
- 自查问句:「这场关键戏是让读者逐拍看到的,还是被告知结果的?」占比不足 → 展开重写。
- 打斗附加判据:交锋段平均句长 ≤15 字(蓄势/对峙段可放长);连续 3 段停在同一景别(远/中/近)= 违规;开战首段须有一次远景定位(空间/人数/地形);一场新招亮相 ≤2 个;每场 ≥1 次环境要素改变战局且该要素开战前已出现;败方按其智力止损(逃/降/换目标),不站桩挨打;胜方损耗在战后 1–2 章内可见。

## 六、智商漂移

角色关键决策低于其已立信息量或智力设定 = 漂移(明知情报仍中计/既定谨慎人设无由莽撞/反派弃用已展示的胜手)。两问自查:

1. 该角色此刻已知道什么——这个决策配得上他已知的信息吗?
2. 换成全书更聪明的角色会怎么做——差距有没有已埋的剧情理由(情绪失控/信息被断/性格弱点)?

两问任一答不出且无已埋理由 → 违规:改写决策,或补铺垫。

## 七、判定输出要求

每条命中须给:定位(引该段起始字句,≤20 字)+ 病名 + 可执行修法(具体到"改成什么样",或用第三节修法三选一)。只报病不给修法 = 无效评审。
