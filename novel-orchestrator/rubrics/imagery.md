# 判据卡 · 意象系统与描写(imagery)

> 自包含判据卡:意象系统(形象系统)纪律、描写六要诀、比喻预算。traditional 路线语言遍主用;style.md「比喻与意象纪律」节的验收依据;深评抽查跨章意象漂移。适用对象:style.md 定稿评审、章级正文语言验收、全书修订「语言遍」。

## 一、意象系统纪律(书级,style.md 验收)

意象系统 = 全书反复出现、随主题增值的**意象域**(如「水/溺没」「牢笼/门」「火/灰烬」),不是单章修辞。

| 判据 | 违规信号 |
|---|---|
| 意象域 ≤3 个/书,写入 style.md「比喻与意象纪律」节 | 未登记(全凭写手即兴)或 >3 域(稀释) |
| **内部形象法**:意象取自故事世界内部实存事物 | 外部借用(取自故事世界不存在的文化符号——古代世界用"过山车"式喻体) |
| 隐性运作:意象出现于场景细节/环境/动作,不点破 | 叙述者点破象征义(「这扇门,正如他的心门」)= 命中即违规 |
| 随主题增值:同一意象域每次复现应对应价值轴的新位置 | 复现零变化(纯装饰重复) |

## 二、比喻预算(章级,与 prose-disease §二联判)

| 检查项 | 阈值 |
|---|---|
| 单章比喻密度 | 关键场面 ≤3 处/千字;日常场面 ≤1 处/千字——超限 = 修辞噪音 |
| 同喻体复用 | 单章同喻体 ≥2 = 预警;全书累计 ≥3 = 超限入黑名单(prose-disease §二同款) |
| 喻体域一致 | 单章 ≥2 处比喻取自登记意象域之外 = 漂移信号,深评抽查 |
| 通感/奇喻 | 每章 ≤1 处;连续 2 章使用 = 炫技预警 |

## 三、描写六要诀(段落级验收)

| 要诀 | 判据 |
|---|---|
| 具体细节 | 描写落在可感细节上;「美丽/宏伟/可怕」类抽象形容连用 ≥2 = 违规 |
| 具体名词 | 「一棵树/一辆车」应为「一棵歪脖子枣树/一辆掉漆的二八杠」——泛名词密集段 = 返修 |
| 动作名称 | 静态清单式描写(从头到脚/从左到右罗列)>4 句 = 违规;描写应挂在动作与视线移动上 |
| 少系动词 | 「是/有/在」担纲的句子在描写段占比 >50% = 违规 |
| 删除冗余 | 双重修饰(「冰冷刺骨的寒风」)、同义反复(「孤身一人独自」)命中即删 |
| 段落节奏 | 描写段连续 >5 句无人物动作或感知介入 = 违规(景在动,人不能死) |

## 四、感官锚与视角纪律(场景级)

1. 每个场景至少一个**非视觉**感官锚(声/嗅/触/温/体感);全章纯视觉 = 返修。
2. 描写必须过**视角滤镜**:所见细节与用词符合视角人物的身份、情绪与注意力(木匠看门先看榫卯,逃犯看门先看锁)——通用镜头式描写 = 视角失焦。
3. 情绪外化:禁「他很悲伤」式标签;情绪经由动作/生理/感知选择性呈现(联判 prose-disease 情绪标签病)。
