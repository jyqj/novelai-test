# 判据卡 · 主题与主控思想(theme)

> 自包含判据卡:主控思想公式、思想-反思想对抗、说教检测。traditional 路线书庭/卷庭与深评主用;web 路线书庭 S1 亦可引用(主旨节验收)。适用对象:book「主旨与主控思想」节、卷蓝图「卷主旨与价值走向」节、深评方向偏航判定、全书修订「场景遍」。

## 一、主控思想公式(书级验收)

主控思想 = **「价值 + 原因」一句话**:「(某价值)得以(胜出/沦丧),因为(某原因)」。
例:「正义得以伸张,因为主角比罪犯更执拗」;「爱情走向毁灭,因为双方都把控制当成了爱」。

| 判据 | 违规信号 |
|---|---|
| 可一句话表述,含价值极性与因果 | 「本书探讨人性/成长/救赎」——只有话题没有立场 |
| 原因是**人物行为模式**,不是抽象概念 | 「因为命运/时代」——人物被豁免,主题不可演证 |
| 全书高潮必须**演证**该句(行动证明,非台词宣布) | 高潮打完,主控思想换成另一句才说得通 = 偏航 |
| 一书一主控思想;子主题须服务或反衬它 | 各卷各讲一个互不相干的道理 |

## 二、思想-反思想对抗(结构验收)

主题不是重复,是**辩证**:全书节拍应在「思想」(主控思想的正题)与「反思想」(其最有力的反命题)之间交替摆动,反思想必须获得**真实的胜利回合**。

| 检查项 | 判据 |
|---|---|
| 反思想具象化 | 反派/对立阵营/环境至少一方是反思想的代言,且其论证在剧情内自洽(不是稻草人) |
| 交替节拍 | 正反思想各自的「得势段落」交替出现;正题连胜 ≥3 个大节拍 = 说教化前兆 |
| 反思想最强时刻 | 高潮前应有一次反思想几乎成立的时刻(主角动摇/正题看似破产);缺失 = 主题无重量 |
| 胜负代价 | 主控思想最终胜出必须付出不可逆代价;零代价胜利 = 主题廉价 |

## 三、说教检测(逐章可判)

| 判据 | 阈值 |
|---|---|
| 角色替作者演讲 | 单段主题性议论(角色或叙述者直接陈述"道理")>3 句 = 命中 |
| 结尾升华 | 章末/卷末总结性抒情或点题 >3 句 = 命中(与 prose-disease 章末总结腔联判) |
| 无辩驳布道 | 主题性对话中一方只负责点头/被说服,零有效反问 = 命中 |
| 道理先于事件 | 先给结论再安排情节演示(事件沦为例题) = 命中 |
| 标签化站队 | 持反思想的角色被写矮(降智/丑化)以让正题赢 = 命中 |

修法方向(评审建议用语):把议论改成**选择**——让人物在压力下用行动表态;把结论台词改成让读者自己得出结论的事件排列。

## 四、主题贯穿追踪(卷末/全书修订用)

1. 逐卷写一句「本卷把主控思想推进/挑战到什么程度」——写不出 = 该卷主题空转。
2. 主角关键抉择(每卷 ≥1 次)是否都落在主控思想的价值轴上?旁轴抉择过多 = 主线电缆与主题脱钩(联判 rubrics/structure.md §一)。
3. 结局检查:主控思想的最终演证是否由**主角的主动选择**完成?(被动获救/外力解决 = 主题被机械降神)
