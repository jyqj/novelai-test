# 判据卡 · 场景价值(scene-value)

> 自包含判据卡:场景=价值变化的最小单位。traditional 路线的主力验收卡(web 路线爽点窗口降级后,本卡的「每章价值翻转」即硬指标);深评与全书修订「场景遍」同用。适用对象:细纲(task.json beats/scene_intents/turn)评审与章级正文验收。

## 一、场景合法性(每个标「场景」的拍逐个过)

一个合法场景必须同时满足三条;缺任一 = 该拍是**伪场景**(降级为过场,或补齐后重标):

| 条 | 判据 | 违规信号 |
|---|---|---|
| 有目标 | 场景中至少一方带着可一句话表述的具体意图进场 | 人物"在聊天/在赶路",没人要什么 |
| 有障碍 | 意图遭遇阻力(他人/环境/自身),且阻力被写出来 | 想要→直接得到,零对抗 |
| 有转折 | 场景结束时至少一个价值极性翻转(见二) | 进场和出场处境完全一样 |

过场(交代/位移/衔接)合法,但**连续 2 拍过场 = 违规**;单章过场拍占比 >1/3 = 违规。

## 二、价值翻转判据(turn 验收)

- 每章 task.json 的 `turn` 字段(traditional 细纲必填)= 本章价值翻转一句话,**极性必须标明**(如「信任+ → 背叛-」)。
- 验收三问:① 翻的是哪条价值轴?(答不出 = 无翻转)② 章首极性与章尾极性是否相反或明显升降档?(同极同档 = 平章)③ 翻转是由场景内的行动/揭示导致,还是叙述者宣布的?(宣布 = 概述体违规,见四)
- **连续 3 章无价值翻转 = FAIL 级违规**(route-traditional §1;深评把关)——这是 traditional 路线替代爽点窗口的底线节拍。
- 同轴同向连翻 ≥3 章(一直更好/一直更糟)= 单调,评审应要求插入反向拍。

## 三、场景五步完整性(细纲批次评审用)

对细纲标「场景」的拍抽查(每批次 ≥30%),按五步核:

1. **激励事件**:什么打破了场景内的平衡?
2. **意图升级**:受阻后人物的第二手准备是什么?(没有第二手 = 对抗浅)
3. **鸿沟**:人物预期与实际结果之间是否有落差?(期望=结果 = 无戏)
4. **转折点**:落差通过**行动**还是**揭示**兑现?(标明哪一种)
5. **出口**:场景结束时的新处境如何喂给下一场景?(喂不出去 = 孤岛场景,删或合并)

## 四、关键场面禁概述体(与 prose-disease §五联判)

- 细纲标为本章高潮/对决/告白/揭示的场景:对话+动作节拍合计占比 **≥60%**,概括叙述与心理总结合计 ≤40%。
- 判定问句:「这场戏是让读者逐拍看到的,还是被告知结果的?」被告知 = 重写。
- 「一番激斗,他险胜」「两人聊了很久,终于和解」句式出现在关键场面 = 命中即违规。

## 五、章级配比与节拍(正文验收)

| 检查项 | 判据 |
|---|---|
| 场景/过场配比 | 场景拍 ≥2/章;全部过场的章 = FAIL(不存在合法的纯过渡章) |
| beats 兑现 | 细纲 6–10 拍逐拍可在正文定位;漏拍 ≥2 = 返修 |
| 500 字增量 | 每 500 字 ≥1 个新信息或价值变化(与 prose-disease 水字判据同源) |
| 章内张弛 | 连续 3 个同烈度场景 = 平;高潮场景前应有一次降压拍 |
