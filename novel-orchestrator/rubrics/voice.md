# 判据卡 · 角色声纹(voice)

> 自包含判据卡:声纹卡五件 + 遮名抽检法,治"千人一腔/对话同质化/角色可互换"。适用对象:人物卡设计评审(声纹卡合格性)与章级对话评审(正文守卡情况)。

## 一、声纹五件(一张合格声纹卡的构成)

| 件 | 说明 | 判定要点 |
|----|------|----------|
| 口癖 | 专属词/开口短语 | **≤3 条**(多了写不稳、读者记不住) |
| 句长倾向 | 短促祈使/长句绕弯/省略主语等句式惯性 | 须可操作("句子短、常省主语"合格;"说话有个性"不合格) |
| 词域 | 取词的经验域(行伍/市井/书斋/黑话)——他的比喻和骂人话从哪个域里拿 | 具体到域,能据此造句 |
| 禁用词 | 受身份/教养/时代约束**说不出口**的词 | 比口癖更防同质化;禁用词应指向他不敢碰的东西(信念/创伤层) |
| 标志动作 | 说话时的伴随动作/习惯性停顿 | 1–2 个 |

建卡纪律:
- 主角与核心配角(secondary 及以上):五件全填;次要配角(tertiary):填速记三件(口癖/句式/标志动作)。
- 每卡须有 sample_line:一句最像他的话(含标志动作),作后续对照样本。
- 层次挂钩:口癖露的是表象/行为层;禁用词护的是信念/创伤层——两者功能不同,不可互相顶替。
- 分层纪律:全书叙述层黑名单(style 卡)与单角色对话层禁用词是两层,不互相重抄。

## 二、遮名抽检法(章级对话评审的核心手法)

操作:抽本章对话 5 句,遮去说话人与提示语,只看台词按声纹卡指认说话者。

| 检查项 | 通过判据 |
|--------|----------|
| 遮名指认 | 命中 ≥4/5;<4/5 = 声纹失守 |
| 卡间区分度 | 同场景任意两角色的声纹卡五件重合 ≤2 件;≥3 件 = 卡同质化,须改卡(设计问题,非正文问题) |
| 口癖频率 | 单角色口癖每章出现 1–2 次为宜;连续 3 章 0 次 = 声纹漂移;单章 ≥4 次 = 复读机 |
| 禁用词零命中 | 该角色台词中其禁用词出现 0 次;命中即违规(引出处) |

## 三、判定输出要求

- 失守指认到句:引原文台词 + 应属角色 + 违反声纹卡哪一件。
- 区分两种根因并分开报告:**正文没守卡**(修正文)vs **卡本身同质**(上报改卡)。

## 四、示例(判定手感校准)

老镖师:口癖"走镖的规矩";句长短促、常省主语;词域 = 镖行切口+牲口行话(骂人"劣马性子");禁用词 = 从不说"怕"(创伤:一趟死了人的镖);标志动作 = 开口前先摸刀镡。徒弟夜里问"师父,你怕过吗",他答:「——牲口都喂了?」回避+词域+标志动作三件同时在场,遮名可认。
