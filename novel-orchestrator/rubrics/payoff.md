# 判据卡 · 爽点与期待账户(payoff)

> 自包含判据卡:爽点类型学、密度窗口、期待账户守恒。管"读者情绪账"——爽点管兑现那一下,期待账户管兑现之间读者为什么留下。适用对象:卷蓝图爽点大节奏与弧计划爽点操作表(设计期)、章级兑现核查(评审期)。

## 一、爽点六型触发条件表(无触发条件 = 空转,名义兑现不算数)

| kind | 情绪内核 | 触发条件(缺此条件即空转) | 设计/核查要点 |
|------|----------|--------------------------|----------------|
| dopamine 即时爽 | 压抑→释放 | 前文已积累明确压抑(轻视/亏欠/挑衅),读者可指认 | 先压后放;压抑与释放同章或隔 1–2 章;释放动作公开可见(须有见证者) |
| upgrade 升级 | 投入→回报 | 成长轴已有可见投入(修炼/代价/资源消耗) | 提升结果可验证(对照战力锚定表);升级后 1–2 章内给一次"用武之地" |
| reveal 揭示 | 悬念→解惑 | 已有悬念账户(悬念线已推进至可收状态) | 揭示须重排已知事实的意义,不只是补新信息 |
| reversal 反转 | 预期→颠覆 | 前文 ≥2 次暗示已诱导读者形成稳定预期 | 反转须回溯可信(预埋证据链);禁无预埋硬反转 |
| emotion 情感 | 积累→共鸣 | 关系线已有 ≥2 次推进记录 | 用具体动作/细节兑现,不用抒情段直陈 |
| humor 幽默 | 紧张→松弛 | 位于高压段落之后 | 锚定角色声纹,不齣戏、不打断张力主线 |

(other 为 schema 兜底值,不做设计目标。)

## 二、密度窗口与章型阈值

| 检查项 | 阈值 |
|--------|------|
| 小爽密度 | 任意连续 3 章窗口 ≥1 条已兑现爽点 |
| 大爽密度 | 任意连续 10 章窗口 ≥1 次处境级释放。大爽 = 改变主角处境或公开位阶的释放(通常为 upgrade/reveal/reversal 且伴随处境跃迁) |
| 开篇章 | 前 3 章每章 ≥1 小爽 |
| 过渡章豁免 | 铺垫/过渡章可豁免小爽,但连续豁免 ≤1 章,且该章须含期待动作(第四节四拍之一) |
| 高潮章叠加 | 可多型叠加但单章 ≤3 条(防稀释) |
| 卷末章 | 必含 ≥1 大爽 |
| 卷级规划 | 卷蓝图处境级释放落点 ≥ 卷章数/10 处 |

## 三、同型递减(换型纪律)

- **同 kind 连续命中 ≥3 章即违规**;第 3 章起必须换型或升维。
- 同型内加码(数值更大、场面更响)不算换型。
- 同一手段/同一套路全书重复 ≤2 次,第三次读者无感(回报递减)。

## 四、期待账户

**四拍循环**:
1. **承诺**:亮出可预期的价值目标,须具体可想象——"拿到秘境入场资格"优于"变强"。
2. **升级**:兑现前至少推进一次,三选一:加码(赌注变大)/加险(障碍变强)/加料(新信息使期待更具体)。
3. **兑现**:正面兑现,或"兑现但变形"(得到了,但代价/形态出人意料)。
4. **新承诺**:兑现的同章或次章内,开出 ≥1 个新期待。

**账户余额** = 当前未兑现且读者可感的承诺数:
- 健康区间 **2–5**:主线级 1 条(贯穿本卷)+ 中线 1–2 条(5–15 章)+ 短线 1–2 条(1–5 章)。
- 余额 >5:读者记不住且兑现压力堆积;<2:追读动力不足。
- **守恒律**:每兑现一个承诺,必须新开至少一个。

## 五、断裂判据

| 信号 | 判定与处置 |
|------|-----------|
| 连续 3 章无"升级/新开"动作 | 黄灯:下一章必须补一拍 |
| 连续 5 章既无新承诺也无升级 | 违规:期待链断裂 |
| 兑现后同章+次章均未开新承诺 | 违规:账户漏项,补开 |
| 承诺开出后 >15 章无任何推进 | 告警:转线索对账(防悬置死线) |

## 六、台账完整性(评审核查)

- 每章爽点计划 ≥1 条且已回写兑现状态;未兑现条目须移入后续章或写明原因,禁止静默丢弃。
- 每条已兑现爽点能指出其压抑/投入/悬念来源(章号或线索 id);指认不出 = 空转,不计入密度。
