# 判据卡 · 防抄袭与融梗边界(anti-plagiarism)

> 自包含判据卡。LLM 的风险不是"想抄",而是训练语料**无感复现**——顺手写出的专名、金句、桥段可能是别人的。适用对象:设定提案(设计期)、名场面细纲(细化期)、正文抽检(评审期)。

## 一、三级判定表(核心判据)

| 层级 | 对象 | 边界 | 处置 |
|------|------|------|------|
| 设定级 | 类型公共资源:修炼位阶概念、系统面板、克苏鲁式神话框架、副本/位面 | **可借鉴**:概念可用,命名与组合必须原创 | 沿用他书专名 → 按第二节专名撞车处理 |
| 桥段级 | 具体情节组合:退婚开局、当众打脸、夺舍重生等名场面 | **须变形 ≥2 要素**。五要素:人物关系/动机/场景/手段/结果 | 变形 <2 要素 = 违规,重排 |
| 文字级 | 句段表达 | **零容忍**:连续 ≥12 字非公共表达复现即违规(成语、俗语、公共引语豁免) | 必改写 |

## 二、专名撞车自查

1. 本书应有专名词表(人名/功法/组织/地名/金手指名);评审时先索要或对照,词表缺失即列流程违规。
2. 每个专名做检索比对:有本地语料库用 `rg "专名"` 扫描;无语料库用站内与全网检索"专名+小说"。
3. 与知名作品核心专名同名 = 违规必改(例:新书宗门起名"青云门"即撞《诛仙》核心专名)。
4. 每卷新增专名须入表复查;卷末应能答"本卷新增专名均已过查"。

## 三、金句复现警戒

- 高危区:章尾钩句、宣言句、道理句(语料复现最常发生处)。
- 抽检法:每章抽 3 句最"漂亮"的句子做检索比对;命中连续 ≥12 字 = 按文字级零容忍处理。

## 四、名场面还原度三问(桥段级抽检)

1. 读者能否直接叫出"这是某书某场面"?
2. 把本书专名换回原作专名,是否毫不违和?
3. 关键道具、标志台词、动作设计,是否 ≥2 项与原作相同?

任一"是" → 按桥段级要求变形 ≥2 要素后重写。

## 五、对比填充法安全边界(参考成熟作品做结构时)

| 边界 | 内容 |
|------|------|
| 结构可学 | "入城→结识权贵→卷入夺嫡→扬名"这类功能序列可提取 |
| 表达必须重写 | 任何句段不得照搬 |
| 专名必须原创 | 人名、功法、组织零沿用 |

填充完成后按桥段级复检:与参考卷同位置事件须 ≥2 要素不同。

## 六、通过判据汇总

| 检查项 | 通过判据 | 违规处置 |
|--------|----------|----------|
| 专名词表 | 词表存在;新增专名均已过查;无知名作品核心专名撞车 | 撞车 = revise 必改 |
| 金句抽检 | 每章 3 句高亮句无连续 ≥12 字复现 | 命中 = revise 必改 |
| 桥段变形 | 可指认的借鉴桥段均列得出 ≥2 处要素变形 | 不足 = revise 重排 |
| 名场面三问 | 三问全"否" | 任一"是" = revise |
| 填充复检 | 对比填充产物与参考卷同位事件 ≥2 要素不同 | 不足 = revise |

判定示范:借"克苏鲁神话框架"(不可名状存在、疯狂与污染代价)属设定级公共资源,合法;但途径体系、组织名、神名必须全原创。反面:照搬"退婚受辱→当众立誓→三年后打脸"且只改人名地名,五要素一个未动 = 桥段级违规。
