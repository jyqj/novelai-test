# 第一部分：核心概念与理论基础

<!-- K-CHAR-001 -->
## 一、人物塑造VS深层性格（麦基核心理论）

这是人物设计中最根本的区分，也是大多数创作者混淆不清的概念。

### 1.1 人物塑造（Characterization）

> **定义**：一切可以观察到的人的素质总和，一切通过仔细考察便可获知的东西。

人物塑造包括：
- **外在特征**：年龄、性别、外貌、穿着打扮
- **社会属性**：职业、教育、经济地位
- **行为风格**：语言习惯、手势动作、生活方式
- **表面性格**：性格特点、价值观念、态度取向

这些特质的独一组合使每个人物独一无二——但这**不是**人物的真正本质。

### 1.2 深层性格真相（True Character）

> **定义**：人物性格真相在人处于压力之下做出选择时得到揭示——压力越大，揭示越深，其选择便越真实地体现了人物的本性。

深层性格揭示的是：
- 这个人**到底是谁**？
- 他是充满爱心还是残酷无情？
- 慷慨大方还是自私自利？
- 英勇无畏还是猥琐怯懦？

> **核心法则**：得知真相的**唯一方法**就是看他如何在压力之下做出选择，在追逐欲望的过程中采取哪种行动。

### 1.3 二者关系的本质

| 层面 | 人物塑造 | 深层性格真相 |
|------|----------|--------------|
| 可见性 | 表面可见 | 深层隐藏 |
| 获取方式 | 观察即可获知 | 只能通过选择揭示 |
| 作用 | 使人物可信 | 使人物有深度 |
| 变化性 | 相对稳定 | 可在故事中改变 |
| 比喻 | 面具 | 面具下的真相 |

### 1.4 为什么这个区分至关重要

> **生活教给我们的宏大原则**：看似如此，其实并非如此。人不可貌相。表面特征下掩盖着一个深藏的本性。

当人物塑造和人物真相完全吻合，当内心生活和外在表现就像一块水泥一样同为一物时，这个角色便变成了：
- 重复出现的
- 可以预见其行为的
- 一份人物目录

这样的人物并非不可信——浅显和没有维度的人的确存在——**但他们实在乏味**。

## 二、七大核心原理概览

### 原理一：主线与目标——让每个人物都是自己故事的主角

人物的主观能动性来源于明确的目标追求。每个重要角色都应该是自己生命叙事的主角。

**核心要素**：
- **独立主线原则**：每个重要角色都需要独立的故事线和人生目标
- **主角意识原则**：让角色相信自己是故事的中心
- **目标层次性**：从终极目标到即时需求的完整体系

**关键洞见**：目标设计的误区在于过于功能化。正确做法是赋予独立目标，让目标在追求过程中自然影响到其他角色。

### 原理二：动机设计——目标背后的深层驱动力

目标是"要什么"，动机是"为什么要"。表面目标下隐藏着更深层的心理动机。

**核心要素**：
- **动机多样性**：相同目标可以有完全不同的动机
- **动机层次**：表层动机、深层动机、核心动机的递进关系
- **动机冲突**：不同动机产生不同的行为模式和道德边界

**关键洞见**：动机决定了人物的行为模式、合作对象、冲突时机和最终选择，是人物行动的根本逻辑。

### 原理三："屁股决定脑袋"——情境化的人物表现

同一个人在不同的社会角色、权力关系、亲密程度下会展现完全不同的面貌。

**核心要素**：
- **角色面具原则**：每个人物都有多张"社交面具"
- **权力距离原则**：权力关系影响行为表现
- **情境适应性**：真实自我在面具切换中逐渐显露

**关键洞见**：人物在不同情境下的表现差异，正是其复杂性和真实性的体现。

### 原理四：关系演变——动态的人物互动

人际关系是动态发展的，会经历不同阶段。静态的人物关系缺乏真实感和戏剧张力。

**核心要素**：
- **关系阶段性**：初识、磨合、稳定、变化的发展轨迹
- **双向影响**：关系改变影响人物表现，人物成长影响关系性质
- **转折点设计**：关键事件催化关系质变

### 原理五：洋葱式性格——层层剥开的人物深度

从表层的社会面具到深层的潜意识驱动，人物的真实面貌需要逐层展现。

**五层结构**：
1. 表象层——社会形象
2. 行为层——处世方式
3. 情感层——情感需求
4. 信念层——价值观念
5. 核心驱动层——创伤/欲望/信念/气质（四选一）

**关键洞见**：每一层都不是孤立的，而是核心驱动的不同表现。这种设计让人物的每个行为都有深层依据。

### 原理六：反差张力——利用内在冲突创造戏剧性

最有力的冲突往往来自人物内心的矛盾性格。维度不是特征的堆砌，而是矛盾的设计。

**核心要素**：
- **矛盾共存**：对立特质在同一人物中共存（如野心与负疚、理性与冲动）
- **张力外化**：内在矛盾转化为外在冲突，在关键时刻爆发
- **压抑与释放**：矛盾面的积累和爆发形成戏剧节奏
- **连贯一致**：矛盾必须有内在逻辑支撑，而非随意添加的怪癖

两种矛盾形式与"踢猫"反例，详见第二部分"人物维度与矛盾"（K-CHAR-008），此处不重复。

### 原理七：关系镜像——通过他人展现自我

"镜像自我"理论指出，我们通过他人的反应认识自己。精心设计的人物关系网络是展现人物性格的最佳途径。

**核心要素**：
- **关系功能性**：每个关系展现人物的某个侧面
- **互动深化**：通过互动而非说明展现性格
- **关系类型**：镜像、互补、对抗、依赖等多种关系
- **动态演变**：关系随故事发展而变化，展现人物成长

**关键设计原则**：
- 每个重要关系都应承担独特的性格揭示功能
- 避免功能重复——若两个关系揭示的是同一特质，考虑合并或重新设计
- 关系的变化应与人物弧光同步，互相印证

**关键洞见**：孤立的人物描写是苍白的，性格只有在关系互动中才能被充分揭示和检验。

## 一、压力下的选择——揭示性格真相的唯一途径

> **交叉引用**：压力的来源是对抗力量。关于如何设计强大的对抗力量、如何构建压力递进，详见《04-冲突与对抗力量》。本节聚焦于：在压力之下，人物的选择如何揭示其深层性格。

### 1.1 压力是根本

> **在没有任何风险的情况下做出的选择意义甚微。**

| 压力等级 | 情境举例 | 揭示程度 |
|----------|----------|----------|
| 无风险 | 无利害关系下的选择 | 微不足道 |
| 低压力 | 小损失/小收益的选择 | 初步倾向 |
| 中压力 | 重大利益的选择 | 深层倾向 |
| 高压力 | 生死或核心价值的选择 | 核心性格 |
| 极限压力 | 本能反应的瞬间 | 无意识真相 |

### 1.2 揭示的层次递进

人物深层性格的揭示是一个渐进过程：

1. **初步选择**——提供人物线索
2. **动机判断**——揭示更多信息
3. **行动方式**——深层揭示性格
4. **极端压力下的选择**——触及性格核心
5. **本能反应**——暴露无意识的真相

### 1.3 经典思想实验：校车事故

**场景设定**：
- 一辆锈蚀的客货两用车（非法移民清洁工）
- 一辆光可鉴人的保时捷（神经外科大夫）
- 两人的人物塑造特征**正好相反**

**压力测试**：校车着火，学童被困

**递进选择序列**：

| 选择层次 | 问题 | 揭示内容 |
|----------|------|----------|
| 第一层 | 谁选择停车？谁继续前行？ | 初步人物线索 |
| 第二层 | 停下来是为了帮忙，还是被吓住了？ | 更多信息 |
| 第三层 | 谁去打电话？谁冲进火中？ | 深层性格揭示 |
| 第四层 | 最后一秒救哪个孩子？ | 无意识的真相 |

**结论**：压力之下的选择将会剥下人物塑造的面具，我们将窥探到他们的内在本性。

## 二、人物维度与矛盾

### 2.1 什么是"维"？

> **维是指矛盾：无论是在深层性格之内，还是在人物塑造和深层性格之间。**

两种矛盾形式：
- **深层性格内部的矛盾**：如麦克白的"野心"与"负疚"
- **人物塑造与深层性格之间的矛盾**：如"魅力四射的小偷"

### 2.2 关键要求：矛盾必须连贯一致

> **把一个人通篇塑造成一个好人，然后在一个场景中让他去踢一只猫，并不能增添这个人物的维。**

矛盾不是随意添加的怪癖，而是有内在逻辑支撑的对立统一。

### 2.3 哈姆雷特：维度的极致

哈姆雷特不只是三维，而是十维、十二维：

| 矛盾维度 | 表现 |
|----------|------|
| 信仰维度 | 既有信神的表现，又有渎神的实质 |
| 情感维度 | 对奥菲利娅起初充满爱心，后又铁石心肠 |
| 行动维度 | 既果敢又怯懦，时而冷静时而冲动 |
| 态度维度 | 无情又有情，孤傲又自怜 |
| 心智维度 | 机智又悲哀，清醒又迷茫 |

> **他是一个活生生的矛盾体，包容了我们所能想象的几乎任何人性特质。**

### 2.4 维度法则

> **主人公必须是全体人物中最多维的一个人物，以将移情焦点集中在这一明星角色身上。**

否则善之中心就会偏离，虚构的宇宙就会崩溃，读者就会失去平衡。

> **网文补注**："主人公最多维"不等于压低配角。配角需要的是**功能清晰 + 声纹独特**，而不是低维；群像与配角运营（配角生命周期、反派梯队、声纹卡）见 K-CHAR-011/012/013。

## 三、洋葱式性格详解

### 3.1 五层结构模型

| 层次 | 名称 | 可见性 | 内容 |
|------|------|--------|------|
| 第一层 | 表象层 | 所有人可见 | 社会形象、外在表现 |
| 第二层 | 行为层 | 交往中展现 | 处世方式、行为模式 |
| 第三层 | 情感层 | 对亲近者展现 | 情感需求、真实感受 |
| 第四层 | 信念层 | 压力下暴露 | 价值观、人生哲学 |
| 第五层 | 核心驱动层 | 不直接可见——是上四层的驱动来源 | 核心驱动，四选一：创伤/欲望/信念/气质 |

**各层判定问句与反例**（层界拿不准时逐条自测）：

- **表象层**：陌生人见第一面就能观察到吗？——反例："内心自卑"放表象层是错的，第一面看不到，属更深层。
- **行为层**：打过几次交道后能总结出的做事套路吗？——反例："童年被遗弃"不是行为层，那是经历，属核心驱动层的素材。
- **情感层**：只对亲近者暴露的需求与感受吗？——反例："油嘴滑舌"不是情感层，人人可见，归表象层。
- **信念层**：能写成一句他信奉的"人生公理"吗？——反例："爱喝酒"不是信念层，无价值判断，归表象/行为层。
- **核心驱动层**：这一条能否解释上面四层的大部分表现？（四选一：创伤/欲望/信念/气质）——反例："赌性深重"不是核心驱动，它是驱动之下反复出现的行为模式，归行为层。

**两处"信念"重名区分判据**：第四层"信念层"的信念 = 角色自己能说出口的价值观（可自述的人生公理）；第五层驱动选项的"信念" = 生成上面四层的根因。若第五层选"信念"，须写明"为何持有此信念的根因事件"（何时何事使其信此），写不出根因事件的条目应归第四层。

### 3.2 韦小宝案例解析

| 层次 | 展现 | 内在呼应 |
|------|------|----------|
| 表象层 | 贪财好色、油嘴滑舌 | ← 需要外在享受和表演来消解自卑 |
| 行为层 | 机智圆滑、贪生怕死、赌性深重、敢于冒险 | ← 底层生存法则的体现，缺乏安全感 |
| 情感层 | 重情重义、渴望认可 | ← 妓院孤儿的情感匮乏 |
| 信念层 | 相信命运可以改变、富贵险中求 | ← 翻身欲望的价值化表达 |
| **核心驱动层（创伤型）** | **自卑与自大并存** | **妓院出身的身份创伤，一切行为的根源** |

**层界判定示范**："赌性深重"是旁人打几次交道就能总结出的做事模式，归**行为层**；它背后那句"命运可以赌、可以改"的人生公理才归**信念层**。判定法：可被反复观察到的是行为，只在压力下暴露的价值公理是信念。

**关键洞见**：常见设计之一是各层由核心驱动层向外衍生（驱动可为创伤/欲望/信念/气质；此例为创伤型：自卑），让人物的每个行为都有深层依据——但这是推荐手法而非硬性要求。

**层次关系示意**：
- 表象层的"贪财好色"源于核心驱动的自卑——需要物质享受来证明自己
- 行为层的"贪生怕死""赌性深重"源于核心驱动的不安全感与翻身欲望——妓院孤儿的生存本能
- 情感层的"重情重义"源于核心驱动的情感匮乏——渴望弥补童年缺失
- 信念层的"命运可改"源于核心驱动的翻身欲望——想要彻底摆脱卑微出身

## 四、结构与人物的连锁关系

> **交叉引用**：结构通过对抗力量施加压力。关于对抗力量的设计原则（战败狗原则、匹配性原则等），详见《04-冲突与对抗力量》。关于故事结构的层级与23序列法，详见《01-故事结构体系》。

### 4.1 核心论断

> **结构即是人物，人物即是结构。它们是一回事。**

### 4.2 结构的功能

> **结构的功能就是提供不断加强的压力，把人物逼向越来越困难的两难之境，迫使他们做出越来越艰难的冒险抉择和行动，逐渐揭示出其真实本性，甚至直逼其无意识的自我。**

### 4.3 互相连锁的机制

```
故事事件结构 ← 人物在压力下的选择和行动
     ↓                    ↑
人物揭示与改变 ← 人物通过选择和行动被揭示
```

> **如果你改变了事件设计，那么也就改变了人物；如果你改变了人物的深层性格，也就必须再造结构来表达人物被改变了的性格。**

### 4.4 实例说明

**情境**：主人公在轴心事件中选择说真话

| 第一稿 | 第二稿 |
|--------|--------|
| 选择说真话 | 选择撒谎 |
| 人物是诚实的人 | 人物是谎言家 |

人物塑造丝毫没有触动——穿着依旧，干的还是那份工作。但**通过事件的逆转，作者便创造出了一个全新的人物**。

### 4.5 人物设计与23序列法节点的实操关联

> 详细节点定义参见《01-故事结构体系》

#### 人物揭示的关键节点

| 节点 | 人物设计功能 | 揭示层次 |
|------|--------------|----------|
| 节点1（出场时刻） | 呈现人物塑造、展示情感保护壳 | 表象层、行为层 |
| 节点4（开始上路） | 保护壳被击出裂痕，显露脆弱面 | 情感层初现 |
| 节点7（欢迎登船） | 内心冲突浮出水面，揭示创伤成因 | 情感层、信念层 |
| 节点12（前线交战） | 卸下假面，暴露真正需求 | 信念层、核心驱动层 |
| 节点18（全面战斗） | 确信战胜内心冲突，展现蜕变 | 深层性格验证 |
| 节点23（分享果实） | 彻底抛弃保护壳，展现新生活状态 | 人物弧光完成 |

#### 人物成长四步骤与压力设计

| 成长步骤 | 对应节点 | 压力类型 | 设计要点 |
|----------|----------|----------|----------|
| 成长第一步 | 节点8 | 外部威胁压力 | 次要反派的力量展示，迫使主角正视问题 |
| 成长第二步 | 节点12 | 抉择压力 | 无路可退的十字路口，必须做出重大决定 |
| 成长第三步 | 节点16 | 内在突破压力 | 必须战胜内心冲突才能继续前进 |
| 成长第四步 | 节点19 | 绝望与重生压力 | 从失败中获得启发，重拾信心 |

#### 检验事件设计是否充分揭示人物的方法

**检验问题清单**：

1. **选择检验**：此事件是否迫使人物做出选择？选择是否揭示了其深层性格？
2. **压力检验**：此事件的压力等级是否与预期揭示的人物层次匹配？
3. **递进检验**：此事件的压力是否比前一个事件更大？
4. **层次检验**：到目前为止，人物的五层性格是否都有机会被揭示？
5. **一致性检验**：人物在此事件中的选择是否与其深层性格一致？

**压力-揭示对应原则**：

| 压力等级 | 揭示的人物层次 | 节点位置建议 |
|----------|----------------|--------------|
| 低压力（小利害） | 表象层、行为层 | 节点1-5 |
| 中压力（重大利益） | 情感层 | 节点6-11 |
| 高压力（核心价值） | 信念层 | 节点12-17 |
| 极限压力（生死/灵魂） | 核心驱动层 | 节点18-22 |

# 第四部分：实操方法与工具

<!-- K-CHAR-005 -->
## 一、人物弧光五步设计法

### 第一步：人物塑造的铺陈

**任务**：展示主人公的表面特征和初始状态

**设计要点**：
- 建立清晰的人物塑造特征
- 展示故事开始时的状态
- 为后续揭示埋下伏笔

**案例（哈姆雷特）**：从大学回家参加父亲葬礼，心情极度悲伤、迷茫，恨不得自己已经死去。

### 第二步：深层本性的初步揭示

**任务**：通过选择揭示人物的真实本性

**设计要点**：
- 设计触发事件
- 让人物做出第一个重要选择
- 选择要揭示其本性的某个方面

**案例（哈姆雷特）**：父亲的鬼魂声称被叔叔谋杀。哈姆雷特极力克制冲动，选择等待证据——暴露了他**极度睿智谨慎的本性**。

### 第三步：深层本性与外部面貌的冲突

**任务**：制造内外对照，暗示更深的人物层次

**设计要点**：
- 人物塑造与深层性格形成对照
- 让读者感觉"他不仅仅是这样"

### 第四步：施加越来越大的压力

**任务**：迫使人物做出越来越困难的选择

**设计要点**：
- 压力必须持续升级
- 每个选择都要比前一个更困难
- 选择要触及人物更深的层面

### 第五步：高潮改变人物本性

**任务**：通过故事高潮完成人物的深刻转变

**设计要点**：
- 高潮必须带来人物的深刻变化
- 变化必须由前面的选择序列所支撑
- 新状态要与初始状态形成对照

**平弧（flat arc）补充**：并非所有主角都需要弧光。网文长篇大量使用"人设稳定型"主角——把五步法中的"改变本性"替换为"验证本性"：压力照样升级，但主角以不变的核心驱动反复给出符合人设的选择，新鲜感来自世界与配角的变化。此时的纪律是**人设不崩**：关键抉择不得违背既立人设，口癖、句式、标志动作保持一致（声纹管理方法见 K-CHAR-013 声纹卡）。

# 第五部分：经典案例深度分析

## 案例一：《大审判》——人物弧光的典范

### 人物塑造（开篇）

弗兰克·加尔文出场时是一个波士顿律师：
- 身穿三件套西服
- 举止长相颇具魅力
- **漂亮得不近人情**

### 深层性格揭示

大卫·马梅特的剧本剥开人物塑造的面纱，揭示出：
- 一个腐化、破产、自甘毁灭、无可救药的酒鬼
- 多年来没有打赢过一场官司
- 在报刊讣告中找寻不幸者，赶到葬礼上递名片

### 弧光转折

**触发事件**：有人请他代理一宗医疗事故诉讼。如果庭外调解，他可以马上赚到七万美金。

**关键选择**：当他看到委托人的悲惨状况时，他觉得这个案子所能提供的不仅是一笔唾手可得的丰厚律师费，**更有他灵魂救赎的最后契机**。

他选择向天主教堂和政治权贵集团挑战，**不仅为他的委托人，更为他自己的灵魂而战**。

### 人物弧光完成

这场法律之战将他转变为一个清醒而具有职业道德的优秀律师——他在失去生活意志之前的本来面貌。

## 案例二：兰博VS詹姆斯·邦德——维度的对比

### 兰博的问题

**《第一滴血》**中，他是一个引人注目的人物：
- **人物塑造**：越战老兵，离群索居的独行侠
- **深层性格揭示**：势不可挡、冷酷无情的杀手

**续集的失败**：出山后的兰博没有再经历复杂的人性变化。他把弹药带捆在肌肉上，直到超级英雄的人物塑造和性格真相融合为一个**比卡通还要缺乏维度的角色**。

### 詹姆斯·邦德的成功

三部电影已达到兰博的极限，但邦德系列有将近二十部。原因是：

| 人物塑造 | 深层性格 |
|----------|----------|
| 花花公子 | 具有思想的超级英雄 |
| 身着燕尾服 | 睿智、果敢、致命 |
| 与美女调情 | 能够应对最危险的情境 |

> **这种睿智的超级英雄对其花花公子人物塑造的反衬与揭露，似乎已经变成了一种无穷无尽的愉悦。**

## 案例三：《银翼杀手》——善之中心偏移的教训

### 设计意图
- 市场定位想让读者移情于里克·德卡德这个角色

### 实际效果
- 读者却被更多维的克隆人罗伊·巴蒂所吸引
- 善之中心转移到反面人物身上

### 结果
> **读者的情感迷惑极大地削减了他们的热情，本来应该获得巨大成功的一部影片最后变成一枚哑炮。**

### 教训
主人公必须是全体人物中最多维的，否则善之中心就会偏离，虚构的宇宙就会崩溃。

## 案例四：《无间道》——身份危机与镜像人物

### 镜像人物设计

陈永仁和刘建明的完美对称：

- 都经历身份认同危机
- 都渴望结束双重生活
- 但选择了相反的道路

### 情境化表现的运用

陈永仁在不同情境下的多面性展现，使这个人物具有了丰富的维度。

# 第六部分：常见问题与解决

> **交叉引用**：若问题涉及"对抗力量不足""冲突缺乏张力""反派脸谱化"，请参见《04-冲突与对抗力量》中的问题诊断部分。

## 问题一：人物扁平、缺乏深度

**症状**：
- 人物的外表和内心完全一致
- 读者可以预见人物的一切行为
- 人物像一份可以查阅的目录

**原因**：
- 只有人物塑造，缺乏深层性格
- 没有设计人物塑造与深层性格的反差
- 没有足够的压力情境来揭示深层性格

**解决方案**：
1. 明确区分人物塑造与深层性格
2. 设计二者之间的对照或反衬
3. 创造压力情境，通过选择揭示深层性格
4. 在人物身上设计连贯一致的矛盾

---

## 问题二：人物行为不可信

**症状**：
- 读者觉得"这个人物不会这样做"
- 人物的选择与前面的铺垫不符
- 高潮中的行为与人物塑造冲突

**原因**：
- 人物塑造与高潮设计不匹配
- 缺乏足够的铺垫和过渡
- 深层性格的揭示不够充分

**解决方案**：
1. 检查人物塑造是否支持高潮中的行为
2. 如果不支持，修改人物塑造或修改高潮
3. 在前面的场景中埋下足够的伏笔
4. 确保压力递进让读者相信人物的转变

---

## 问题三：用特征堆砌代替维度

**症状**：
- 人物有很多怪癖和技能
- 但仍然像"电脑桌面一样平板"

**典型错误**：
> "杰西刚从监狱出来，但在号子里潜心钻研金融，是股票专家。他还会跳霹雳舞，获得过空手道黑腰带，还会用萨克斯管吹奏爵士乐。"

**原因**：
- 混淆了人物塑造的丰富性与人物维度
- 用怪癖来装点主人公，却不开启其性格真相

**解决方案**：
1. 维度是矛盾，不是特征
2. 设计深层性格内部的对立
3. 设计人物塑造与深层性格的对立
4. 确保矛盾连贯一致，不是随意添加

---

## 问题四：善之中心偏移

**症状**：
- 读者被配角吸引，而不是主人公
- 配角比主人公更有维度

**解决方案**：
1. 确保主人公是全体人物中最多维的
2. 收敛配角的戏份与揭示深度，而非简单"降维"——配角需要的是功能清晰+声纹独特，不是低维（群像与配角运营见 K-CHAR-011/012）
3. 增加主人公深层性格的揭示机会
4. 将最有力的矛盾保留给主人公

---

## 问题五：结构与人物脱节

**症状**：
- 事件发生了，但人物没有被揭示或改变
- 人物做出选择，但没有推动情节

**解决方案**：
1. 每个重要事件都要迫使人物做出选择
2. 每个重要选择都要推动事件发展
3. 修改事件时同步考虑人物变化
4. 修改人物时同步调整事件设计

---

## 问题六：缺乏成长感

**症状**：
- 故事结束时人物没有变化
- 变化来得突兀、不可信

> **先判弧型再修**：若主角本就是稳定人设型（flat/steadfast），"没有变化"不是缺陷——此时检查的是人设一致性与世界/配角的变化，**人设不崩优先于强行转变**（见第四部分五步法的平弧补充）。

**解决方案**（弧光型主角适用）：
1. 明确起止对比
2. 设计关键事件作为转折点
3. 通过关系变化体现成长
4. 确保弧光五步完整

# 附录：检查清单与速查表

## 一、人物设计完整性检查清单

### 基础检查

- [ ] 人物塑造是否足够丰富，使人物可信？
- [ ] 深层性格是否与人物塑造形成对照或反衬？
- [ ] 是否有独立的人生追求和目标？
- [ ] 动机是否与背景匹配？

### 深度检查

- [ ] 是否设计了足够的压力情境来揭示深层性格？
- [ ] 压力是否在故事进程中持续升级？
- [ ] 人物的选择是否体现其深层性格？
- [ ] 是否通过选择而非说明来揭示性格？

### 维度检查

- [ ] 人物是否具有连贯一致的矛盾维度？
- [ ] 主人公是否是全体人物中最多维的？
- [ ] 内在矛盾（深层性格内部）是否存在？
- [ ] 内外矛盾（塑造与深层性格之间）是否存在？

### 弧光检查

- [ ] 人物弧光是否完整（起点→压力→选择→变化→终点）？
- [ ] 高潮是否带来人物的深刻变化？
- [ ] 人物塑造是否与高潮设计相匹配？

### 关系检查

- [ ] 不同情境下表现是否合理？
- [ ] 关系是否推动成长？
- [ ] 通过关系是否充分展现人物性格？

### 结构连锁检查

- [ ] 事件设计是否能够施加足够的压力？
- [ ] 人物的选择是否推动了事件的发展？
- [ ] 事件设计与人物设计是否互相支撑？

## 二、速查表

### 人物VS人物塑造速查

| 概念 | 人物塑造 | 深层性格（人物） |
|------|----------|------------------|
| 定义 | 可观察的素质总和 | 压力下选择揭示的真相 |
| 包含 | 外表、行为、社会属性、表面性格 | 内心深处是谁 |
| 获取 | 观察即可 | 只能通过选择 |
| 作用 | 使人物可信 | 使人物有深度 |
| 关系 | 面具 | 面具下的真相 |

### 人物维度速查

| 类型 | 定义 | 示例 |
|------|------|------|
| 一维 | 单一但令人执迷的矛盾 | 终结者：机器VS人 |
| 二维 | 外表与内心的矛盾 | 外表美丽仁爱，内心丑陋可恶 |
| 多维 | 多重连贯一致的矛盾 | 哈姆雷特：十余种维度 |

### 人物弧光五步速查

| 步骤 | 任务 | 关键点 |
|------|------|--------|
| 第一步 | 铺陈人物塑造 | 建立初始状态 |
| 第二步 | 揭示深层本性 | 通过选择暴露真相 |
| 第三步 | 制造内外冲突 | 人物塑造与深层性格对照 |
| 第四步 | 施加升级压力 | 迫使更困难的选择 |
| 第五步 | 高潮改变本性 | 完成人物转变 |

### 常见问题快速诊断

| 问题表现 | 可能原因 | 解决方向 |
|----------|----------|----------|
| 人物扁平 | 缺乏深层性格 | 设计内外反差 |
| 行为不可信 | 塑造与高潮不匹配 | 调整塑造或高潮 |
| 特征堆砌 | 混淆维度与特征 | 设计连贯矛盾 |
| 焦点偏移 | 主人公维度不足 | 增加主人公维度 |
| 结构脱节 | 事件与选择断裂 | 建立连锁关系 |
| 缺乏成长 | 弧光不完整 | 设计转折事件 |

### 调整原则速查

1. 功能化 → 独立化
2. 单一化 → 多面化
3. 静态化 → 动态化
4. 表面化 → 深层化

## 结语

> **终极法则**：他选故他在。压力之下的选择将会剥下人物塑造的面具，让我们窥探到他们的内在本性，并在智慧之光闪现之际把握住他们的性格真相。
