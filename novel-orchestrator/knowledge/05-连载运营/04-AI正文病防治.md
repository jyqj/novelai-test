> **文件定位**：针对 LLM 生成正文高发病——口癖复读、打斗糊成一团、章内平铺直叙、水字数，及章末总结化、关键场面概述体、智商漂移——的防治规程。是 critic 抽检轮与 P6 交稿自查的主要方法源；通用写作技法（对话/描写/展示原则）见 `../04-写作实践`。

## 一、口癖与句式重复防治

**适用场景**：P6 每章交稿自查；每 5 章/critic 轮全面对照 canon_style；diagnose「文风漂移/AI 腔/口癖复读」。

### 1.1 黑名单机制

1. `canon_style.taboo_list` 是**全书叙述层**黑名单的唯一登记处（style-card 模板预置常见 LLM 腔，项目按题材增删）；角色对话层黑名单在 `Character.voice.taboo_words`（K-CHAR-013），两层不重抄。
2. 命中即违规、改写后再过 gate——不设「偶尔可以」豁免；高频副词类条目按卡内标注的次数阈值判。
3. 新口癖增补：critic 轮发现同一表述 3 章内重复 ≥3 次 → 判为新口癖，增补进 `taboo_list`（canon 切片 rev++，simple_change 留痕）。

### 1.2 典型 LLM 腔黑名单示例（与 style-card 预置同族，≥12 条）

1. 嘴角勾起一抹（弧度/笑意/冷笑）
2. 眼底/眼中闪过一丝（……）
3. 眸中精光一闪
4. 不由得倒吸一口凉气
5. 空气仿佛凝固了
6. 心中暗道/心中一凛
7. 缓缓开口/缓缓说道
8. 深深地看了一眼
9. 声音很轻，却带着不容置疑的（……）
10. 一道（倩影/身影）闪过
11. 整个人如遭雷击
12. 仿佛要把人吸进去一般
13. 顿时/瞬间/霎时间（高频副词：单章合计 >3 次即违规）
14. 值得一提的是/要知道/殊不知（说明文腔转场语）
15. 这一夜注定（……）/谁也没想到（……）/而这一切，才刚刚开始（章末总结腔类属条目，判据见 §3.4）

### 1.3 句式多样性判据

| 检查项 | 判据 |
|--------|------|
| 同结构连用 | **连续 3 句同结构**（同词性开头 + 同主干型）= 违规 |
| 段首重复 | 连续 3 段以同一人名/人称开头 = 违规 |
| 段尾情绪化 | 连续 3 段以感叹号或抒情短句收尾 = 违规 |
| 比喻漂移 | 单章 ≥2 处比喻取自 `canon_style.imagery_domains` 之外 = 漂移信号 |
| 比喻复用 | 同一喻体全书累计 ≥3 次 = 复用超限，该喻体增补进 `taboo_list`（机制同 §1.1 新口癖增补） |

### 1.4 自查流程（每 5 章/critic 轮）

1. 逐条 `taboo_list` 扫描本批正文（字面条目可直接检索，句式级条目人工抽查）。
2. 抽 3 个高情绪段落跑句式判据四项。
3. 对照 `sample_passages` 语感基准通读一遍，确认无整体漂移。
4. 命中 → repair_in_phase 改写；新口癖入卡；结论与摘引写入 `evidence_checks`。

### 1.5 示例（泛化）

critic 轮发现第 46–50 章「指尖微微一颤」出现 7 次且 3 章内连用：a) 全部按声纹卡差异化改写（老兵改握拳，少女改攥衣角，谋士改摩挲扳指）；b) 「指尖微微一颤」增补入 `taboo_list`，rev++ 留痕。

## 二、打斗场面技法

**适用场景**：`unit_type=action` 的章（P6 白名单挂载）；diagnose「打斗糊/流水账/读者跳战斗段」。

### 2.1 镜头语言（远-中-近切换节拍）

1. 三景别分工：**远景**=战场态势与空间关系（谁在哪、退路何在）；**中景**=攻防回合与身法路线；**近景**=一击的触感、表情、五感细节。
2. 节拍纪律：每个交锋段落内至少完成一次「远→中→近」或「近→中→远」的推拉；**连续 3 段停在同一景别 = 违规**（全远景=看不清痛感，全近景=丢失空间）。
3. 开战首段必须给一次远景定位：空间、人数、地形要素点名。

### 2.2 可判定标准

| 检查项 | 判据 |
|--------|------|
| 短句控制 | 交锋段（兵刃相接的段落）**平均句长 ≤15 字**；蓄势/对峙段可放长 |
| 招式经济 | 一场战斗新招/新能力亮相 **≤2 个**，其余用已知招的新用法（组合/反用/环境放大） |
| 环境互动 | 每场 ≥1 次环境要素改变战局（地形/器物/天候/旁观者），且该要素在开战前已出现过 |
| 景别节拍 | 无连续 3 段同景别 |
| 败方逻辑 | 胜负落在战力锚定表区间内（K-WORLD-022），越阶须三要素+配额（K-WORLD-023）；败方按其智力止损（逃/降/换目标），不站桩挨打 |
| 代价兑现 | 胜方损耗在战后 1–2 章内可见 |

### 2.3 操作步骤

1. 写前列战斗小抄：双方位阶（查锚定表）/环境要素 ≤3 项/本场允许的新招数/预定胜负与代价。
2. 按镜头节拍成文，交锋段刻意压句长。
3. 写后跑判定表 + 抽一段交锋数句长，结论入 `evidence_checks`。

### 2.4 示例（泛化）

码头夜战（主角凝罡 vs 破窍杀手，越阶已登记配额）：远景（雨夜、三条栈桥、吊臂货箱）→ 中景两回合（杀手枪快，主角借货箱遮枪线）→ 近景（枪尖擦颊，铁锈混着血腥味）→ 中景（主角反手斩缆，吊货砸塌中桥=环境互动，缆绳首段远景已交代）→ 近景（拍出一次性雷符=预埋底牌）收束。全场新招 1，交锋段平均句长 12 字；败方杀手断桥后弃战跳水，止损合理。

### 2.5 关键场面须场景化（判据）

`ChapterPlan.content_blocks` 中标记为本章高潮/对决的内容块**禁概述体**——不许「一番激斗，他险胜」式一段带过；该块内对话+动作节拍合计占比 **≥60%**（概括叙述与心理总结合计 ≤40%）。交稿自查与 critic 轮附问句：「这场关键戏是让读者逐拍看到的，还是被告知结果的？」占比不足 → 按 §2.1 镜头节拍展开重写。

### 2.6 智商漂移判据（critic 检查项）

角色关键决策与其**已立信息量或智力设定**冲突 = 智商漂移（判据延伸自 §2.2「败方逻辑」，不限打斗章：明知情报仍中计、既定谨慎人设无由莽撞、反派弃用已展示的胜手）。critic 轮两问自查：「该角色此刻已知道什么——这个决策配得上他已知的信息吗？」「换成全书更聪明的角色会怎么做——差距有没有已埋的剧情理由（情绪失控/信息被断/性格弱点）？」无理由 → repair 改写决策或补铺垫。

## 三、章内微结构

**适用场景**：P5 章纲细化与 P6 写作时的章内布局；diagnose「章末无力/开篇平/章内平铺直叙」。

### 3.1 开头三段钩

1. 首段禁平铺：不以天气/晨起/纯静态环境开头（环境本身即威胁除外）；直接进动作、对话中段或反常细节。
2. **300 字内给一个反预期信号**：与读者对上章章末形成的预期产生偏差（提前发生/变奏/换视角切入），而非字面重复兑现上章钩子。
3. 第三段前完成「本章问题」亮相——读者明确这一章在追什么。

### 3.2 场景转换四法（章内换场只用四种，混用防单调）

| 法 | 用法 | 纪律 |
|----|------|------|
| 时间跳 | 「一炷香后」类硬切 | 跳过的时段内不得藏关键信息 |
| 空间切 | 换地点 | 新场景首句 ≤20 字内点明何地 |
| 视角换 | 换 POV 角色 | 单章 ≤2 次；换后首段内亮明新视角身份 |
| 因果桥 | 上场景的结果 = 下场景的原因 | 最顺滑，占比宜 ≥ 半数 |

### 3.3 章内起承转合与字数配比（route=web 默认 2000–4500 字）

| 段落 | 功能 | 配比 |
|------|------|------|
| 起 | 接上章 + 本章问题亮相 | ~15% |
| 承 | 推进与积累（信息/冲突升级） | ~40% |
| 转 | 本章转折/价值翻转（`value_start ≠ value_end` 的落点） | ~30% |
| 合+钩 | 局部收束 + 章尾钩 | ~15%；钩在最后 ≤150 字内 |

配比是诊断标尺而非硬模板：转落在前半 = 头重脚轻；全章无转 = 平铺（水章信号，转 K-WRITE-021）。

### 3.4 章尾钩与下章首段交接纪律

1. 章尾钩四型轮换：悬念/危机/反转/期待（`hooks.close_type` 登记），**同型连用 ≤2 章**。
2. 下章首段不原地复述钩子——从钩子的「后果侧」或「侧面」进入（开头三段钩的反预期信号即由此来）。
3. 钩子开出后 **≤3 章内须有回应动作**（期待账户纪律，K-STRUCT-021）；放空 = 断链。
4. **章末总结化 = 病**：末段禁「总结/展望/感悟」句式——「这一夜注定…」「谁也没想到…」类章末总结腔列为 `taboo_list` 类属条目（示例见 §1.2 第 15 条）；末段只做局部收束，章尾钩句之前收束 **≤1 句**，多余的感悟段直接删。

### 3.5 示例（泛化）

上章末钩：「门后传来母亲的声音——她三年前已经下葬。」本章首段不写主角开门（复述），改写门外守夜人视角：檐下灯笼的火苗齐齐倒向门缝（侧面+反预期）；第三段亮本章问题（门后的声音到底是谁）；中段两次因果桥换场推进；转=「那声音唤出了只有主角知道的乳名」（价值从怀疑→确信有诈）；章尾钩换型为危机：房梁上多了一道呼吸声。

## 四、正文级水字数判据与修法

**适用场景**：P6 交稿自查与 critic 轮；diagnose「正文水/读者跳读/字数够了但什么都没发生」。注：**支线结构性**注水查 K-CONCEPT-012（原病因不变）；本块管正文句段级的水。

### 4.1 可判定水字标准（命中任一即水）

| 类型 | 判据 |
|------|------|
| 复述已知 | 把读者已知信息换措辞再讲（回忆总结/角色间转述），且未附加新评价或新后果 |
| 无新值对话 | 一段对话结束时信息、关系、情绪三者皆无变化（寒暄/车轱辘拉扯） |
| 静态描写超限 | **连续 >3 句**无人物动作、与冲突无牵连的景物或设定描写 |
| 情绪同义反复 | 同一情绪用 ≥3 个同义句连续渲染（震惊了…不敢相信…难以置信…） |

### 4.2 节奏底线

**每 500 字须有 ≥1 个「新信息或价值变化」**——新事实、关系变动、处境变动、情绪转向四者之一。抽查法：任取一个 500 字窗口，问「读者读完这段比之前多知道/多感到了什么」，答不出 = 水。

### 4.3 压缩三法

1. **并句法**：复述性段落压成一个从句挂在新动作上——「想起昨夜种种，他攥紧了缰绳」替代半页回忆。
2. **换值法**：不删场景就注入新值——让一方带目的进场（要东西/试探/隐瞒），对照 K-WRITE-016 对话三原则（压缩/方向/目的）。
3. **转嫁法**：静态设定改由动作/冲突承载——护城河的宽度用一次失败的跳越写出（K-WRITE-001 展示原则的压缩用法）。

### 4.4 操作步骤

1. 交稿前按四判据全文扫描，标出水段。
2. 每个水段三选一处理：删 / 并句压缩 / 注入新值。
3. 随机抽 3 个 500 字窗口做节奏底线抽查。
4. 结论入 `evidence_checks`（附一处修前→修后对照摘引）。

### 4.5 示例（泛化）

原稿 800 字写主角回城：城门景色 6 句静描 + 与门卒 12 句寒暄 + 半页回忆离城原因。修法：静描压成 2 句并入新信息「守卒盘查比三月前严了一倍」（城中戒严=新事实）；寒暄注值（门卒收过别家银子、多问了一句=新冲突苗头）；回忆并句「三个月前，他是被人抬出这道门的」。800 字压至 300 字，新值 3 处，节奏底线达标。
