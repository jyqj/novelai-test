## 一、配角生命周期状态机

**适用场景**：P2 群像规划、连载中每个新配角登场建卡、卷末（volume_checkpoint）配角存量盘点；diagnose「配角工具人化/人物只进不出越写越多/读者记不住谁是谁」。

### 1.1 状态机与操作步骤

配角一生四态：**登场 → 高光 → 退场 → （可选）回收**。

1. **登场**：建最小 Character 卡（`role: secondary | tertiary`）——一句话功能（他为主线提供什么：信息/资源/阻力/对照）+ 声纹速记三件（K-CHAR-013 简版：口癖 1 条、句式倾向、标志动作）。**无功能不建卡不给名**，纯路人用称谓（「掌柜的」）带过。
2. **高光**：每个有名配角安排 **≤2 章**的高光位——主导一个场景、展示不可替代的价值，偿还读者的记忆成本。高光后仍持续占据主舞台 → 触发升格评估：要么升 `role`（tertiary→secondary）并在 `arc.milestones` 记 `{volume_id, milestone}`，要么强制让位。
3. **退场**：离开当前舞台必须给**明确去向**（一句话：去哪、在干嘛），写入 `facts`；禁止蒸发式退场（写着写着没了）。
4. **回收**：跨卷再用须满足触发条件之一——a) 身上挂着未收 Thread；b) 新卷地点/势力与其去向重合；c) 主题需要镜像对照（K-CHAR-007）。回收前重读旧卡与声纹，防止写成「同名新人」。

### 1.2 只进不出检测（可判定）

| 检查项 | 通过判据 |
|--------|----------|
| 活跃人口上限 | 同时活跃（近 10 章出场 ≥2 次）的有名配角 ≤12；群像题材可放宽至 20，须 Status 声明 |
| 卷新增上限 | 单卷新建有名配角卡 ≤8 |
| 退场账清零 | 卷末盘点：本卷登场配角 100% 有归属（常驻/已退场有去向/回收候选） |
| 僵尸卡 | 连续 2 卷未出场且无未收 Thread → 标 `archived` |
| 功能查询 | 任一配角卡能答出「删掉他，哪条线断」；答不出 = 工具人已废，安排退场 |

### 1.3 示例（泛化）

卷 2 客栈线登场的「账房老周」：功能=向主角递黑市消息（建 tertiary 卡，口癖「按规矩」、句式短、标志动作拨算盘）→ 第 18 章高光一章（冒险烧账本救主角）→ 退场「携家小避祸南郡」（入 facts）→ 卷 4 主角赴南郡，触发条件 a+b（他欠主角一命 = promise Thread + 地点重合）回收：声纹不变、处境已变（盘了新铺子），旧口癖「按规矩」在新语境里产生回响。

## 二、反派梯队与轮换

**适用场景**：P2 反派体系规划、每卷卷初反派配置、卷中期下任反派预埋检查；diagnose「反派疲软/张力不升级/卷间掉量」（症状域 `conflict.escalation`）。

### 2.1 三层梯队

| 层 | 定义 | 生命周期 | 数量纪律 |
|----|------|----------|----------|
| 卷级 Boss | 本卷主对抗力量，卷末高潮清算 | 一卷 | 主位唯一（一卷一反派） |
| 幕后主使 | 跨卷引线持有者（K-CONCEPT-011），经代理人施压 | 多卷 | 同时在场 ≤2 名 |
| 循环骚扰型 | 低成本反复出现的麻烦源（宿敌/小人/敌对机构） | 跨卷间歇 | 出场间隔 ≥3 章，每 10 章 ≤1 次 |

### 2.2 一卷一反派的期待管理（操作步骤）

1. 卷初：卷级 Boss 正面挂牌 ≤卷首 10%（与卷级激励事件同步，K-STRUCT-008 网文换算层）。
2. 卷中：**下任卷级 Boss 在本卷 ≥2 次预埋**——名号先行、手笔先行（一次代理动作）或阴影先行（Boss 背后有人的暗示）；预埋登记为 Thread 或 `payoff_entries` 的 reveal 预算。
3. 卷末：本卷 Boss 清算时，下任反派完成正面挂牌（卷末高潮至新卷前 3 章内）。预埋不足 = 卷间疲软的第一病因。
4. 每卷 Boss 强度对照战力锚定表（K-WORLD-022）定位，威胁须**升维**而不只是升数值（K-CONFLICT-003 长篇再入规则：战败狗每卷重判）。

### 2.3 反派疲软判据

| 信号 | 判定 |
|------|------|
| 本卷 Boss 威胁与上卷持平且无质变 | 疲软（对照锚定表与威胁维度核查） |
| Boss 无独立目标，只为与主角作对而存在 | 疲软（工具反派，按 K-CONFLICT-004 五步法重做） |
| 本卷冲突可用上卷已有手段直接解决 | 疲软（未升维） |
| 幕后主使 >3 卷只闻其名无实质推进 | 疲软（引线断，按 K-CONCEPT-011 对账） |

### 2.4 「更强新敌」外的三种变奏

1. **旧敌变奏**：已败反派换目标/换手段/换立场回归——记忆红利高、建立成本低；须带败后变化，禁止原样复活。
2. **环境敌**：天灾/规则变动/资源枯竭充当卷级对抗力量（对抗力量=总和，K-CONFLICT-006）；须配一个人格化代言人承接戏剧冲突（争夺赈粮的官、抢水源的邻族）。
3. **内部敌**：阵营内讧/理念分裂/主角自身代价反噬（把冲突压回内心+人际层，K-CONFLICT-001）。

纪律：**连续 2 卷禁用同一变奏型**；「更强新敌」本身也计入型别轮换。

### 2.5 示例（泛化）

卷 3 配置：Boss=盐帮堂主（卷级）；幕后=漕运总督（卷 1 已留名，本卷两次手笔：调走巡检、买凶截货）；骚扰型=市舶司小吏（每 10–15 章卡要一次）。卷 3 中段起预埋卷 4 Boss（总督义子接管盐路，两次代理动作），卷 3 末堂主倒台同章义子挂牌。卷 4 若再排「更强的官员」即三卷同型——改用内部敌变奏（帮中元老借胜利分赃分裂）。

## 三、角色声纹卡方法

**适用场景**：P2/P4 建人物卡填 `voice`；P6 对话写作对照与 critic 轮遮名抽检；diagnose「对话同质化/千人一腔/角色可互换」。

### 3.1 声纹五件

| 件 | 说明 | 落点（`Character.voice`） |
|----|------|---------------------------|
| 口癖 | 专属词/开口短语，**≤3 条**（多了写不稳、读者记不住） | `tics[]` |
| 句长倾向 | 短促祈使/长句绕弯/省略主语等句式惯性 | `sentence_style` |
| 词域 | 取词的经验域（行伍/市井/书斋/黑话）——他的比喻和骂人话从哪个域里拿 | 并入 `sentence_style` 注明 |
| 禁用词 | 受身份/教养/时代约束**说不出口**的词——比口癖更防同质化 | `taboo_words[]` |
| 标志动作 | 说话时的伴随动作/习惯性停顿 | 在 `sample_line` 中内嵌体现 |

### 3.2 操作步骤

1. 主角与核心配角（`role` ≥ secondary）五件全填；tertiary 填速记三件（口癖/句式/标志动作）。
2. 与洋葱层挂钩校验（K-CHAR-004）：口癖露的是 `surface/behavior` 层；禁用词护的是 `belief/wound` 层——他不说的词指向他不敢碰的东西。
3. 写 `sample_line`：一句最像他的话（含标志动作），作为后续对照样本。
4. 分层纪律：`tree/style.md` 禁忌节管**全书叙述层**黑名单，实体卡声纹禁词管**单角色对话层**，两层不互相重抄（对照 `templates/style.md` 使用纪律）。

### 3.3 可判定标准（遮名测试）

| 检查项 | 通过判据 |
|--------|----------|
| 遮名指认 | 抽本章对话 5 句遮去说话人，按声纹卡指认，命中 ≥4/5 |
| 卡间区分度 | 同场景任意两角色的声纹卡五件重合 ≤2 件；≥3 件 = 卡同质化，改卡 |
| 口癖频率 | 单角色口癖每章出现 1–2 次为宜；连续 3 章 0 次 = 声纹漂移；单章 ≥4 次 = 复读机 |
| 禁用词零命中 | 该角色台词中其 `taboo_words` 出现 0 次 |

### 3.4 示例（泛化）

老镖师：口癖「走镖的规矩」；句长短促、常省主语；词域=镖行切口+牲口行话（骂人「劣马性子」）；禁用词=从不说「怕」（wound：一趟死了人的镖）；标志动作=开口前先摸刀镡。徒弟夜里问「师父，你怕过吗」，他答：「——牲口都喂了？」回避+词域+标志动作三件同时在场，遮名可认。
