## 一、题材红线与内容安全

**适用场景**：P1 立意与题材定稿前的红线自查（gate 自检项；P1 situational route=web 白名单已含本块）；P6 critic 轮/交稿自查按分级表为本章标档；diagnose「锁章/被举报风险」。

**输入**：Blueprint 草案（high_concept / element_seeds / world_seeds）、目标发布平台名、待查正文章。

### 1.1 构思期红线判定清单（六域）

| 红线域 | 判定问句 | 命中处置 |
|--------|----------|----------|
| 现实政治与体制 | 情节是否需要现实国家机构、政治人物或敏感历史事件作支点？ | 弃用，或整体架空置换 |
| 宗教与民族 | 是否把现实宗教/民族群体写成反派或赋予贬损性设定？ | 置换为架空信仰/族群 |
| 色情与性 | 主线爽点是否依赖性描写才成立？ | 题材级风险：重构爽点结构，使 ≤2 档可承载 |
| 暴力与犯罪 | 是否需要可模仿的犯罪手法细节（制爆、制毒、诈骗话术）？ | 虚化到不可操作粒度 |
| 未成年人 | 是否有未成年角色卷入 3 档暴力或任何性相关情节？ | 绝对红线：改年龄或改情节 |
| 真实人物与近现代史 | 可辨识的真实人物/近现代真实事件是否承担负面戏份（影射可辨识也算命中）？ | 架空置换＋改名变形 |

P1 判定动作：六域逐条答"否"方可过 gate；任一"是"按处置列改造后重答。

### 1.2 单章尺度分级自检表（0–3 档）

暴力、情感两条尺度各自标档，每章各得一个数字：

| 档 | 暴力尺度可写 | 情感尺度可写 |
|----|--------------|--------------|
| 0 | 无肢体冲突 | 无亲密描写 |
| 1 | 动作对抗，受伤结果一笔带过 | 牵手、拥抱、氛围暧昧 |
| 2 | 伤亡可见但不停留：不逐帧写创口、不渲染凌虐过程 | 接吻；再进一步即切场景留白 |
| 3 | 酷刑、血腥凌虐逐帧描写 | 性行为过程直写 |

**工作区间**：连载正文默认上限 = 2 档；3 档禁写，命中即 FAIL，按 1.3 降档改写。连续 ≥3 章暴力 2 档 = WARN（风险与疲劳同时积累，插入低档章）。

### 1.3 正文级安全改写三法

| 法 | 操作 | 合格判据 |
|----|------|----------|
| 虚化 | 镜头拉远、过程改结果（写"尸体已经凉了"，不写凌虐过程） | 档位下降且场景价值转变保留 |
| 置换 | 敏感实体换架空等价物（现实王朝→架空王朝、现实教派→架空神系） | 人名、事件、地名三要素无法同时与现实原型一一对应 |
| 留白 | 切场景、事后侧写（用旁观者反应写恐怖，不写恐怖本身） | 读者可由后果推知发生了什么，文本无过程描写 |

### 1.4 平台条款自查动作（不承诺任何具体条文）

平台规则随时间与地区变动，本块只给动作不给条文：① 开书前检索目标平台**现行**创作规范原文，摘成带日期的 checklist 快照，落入项目笔记或 Decision 留痕；② 本清单是底线并集，平台更严处以平台为准；③ 每卷 checkpoint 复查快照，快照龄 >1 卷即重新拉取。

### 1.5 可判定标准

| 检查项 | 通过判据 |
|--------|----------|
| 红线自查 | P1 六域问句全"否"（或已按处置改造） |
| 章级档位 | 每章标注暴力/情感两档，无 3 档 |
| 连续高档 | 无连续 ≥3 章暴力 2 档 |
| 条款快照 | 存在、带日期、龄 ≤1 卷 |

### 1.6 示例

《庆余年》把皇权、监察院等权力斗争议题整体装进架空"庆国"，现实制度讨论经置换后自由展开——置换法示范。《诡秘之主》写教会、神明与献祭，全部使用自创神系（黑夜女神、风暴之主），不借用现实宗教实体；邪教仪式多以事后现场与旁观者反应呈现——宗教域置换与留白的合并用法。

## 二、毒点防治与负面节拍降档

**适用场景**：P2 粗纲毒点自查、P5 章纲负面节拍编排（两处 route=web 白名单已含本块）；P6 critic 轮扫描（critic_round 白名单已含本块）；diagnose「憋屈/毒点预警」。

**输入**：粗纲或章纲中的压抑段与败局安排、主角品类（无敌流/升级流/谋略流）、`payoff_entries` 台账。

### 2.1 毒点清单与判定问句（七项，命中即改）

| 毒点 | 判定问句 | 红线值 |
|------|----------|--------|
| 憋屈 | 主角处于下风/受辱且未翻盘的状态连续了几章？ | 连续 ≤2 章；第 3 章必须给还手动作或明示还手时间表 |
| 圣母 | 主角是否为陌生人/敌人利益牺牲自己或队友的核心利益（战力、资源、安全、立场）？ | 命中且 2 章内无补偿爽点或利益回流 = 违规 |
| 降智 | 该决策是否低于该角色已立的信息量与智力水位（读者已知他知道 X，他却无视 X）？ | 命中即违规（与《04-AI正文病防治》智商漂移判据同源） |
| 绿帽/NTR | 主角（或读者代入位）的伴侣、明确情感对象是否与他人发生情感或身体越界？ | 零容忍；"疑似/误会"桥段同计 |
| 送女 | 已建立好感度的女性角色是否被当作筹码让渡/许配给他人（性别镜像同理）？ | 零容忍 |
| 抢功无偿还 | 主角功劳被冒领后，揭穿或等价偿还（利益＋名誉）安排在几章内？ | ≤10 章兑现；同一压抑源不得二次使用 |
| 无意义死亡 | 已投入情感的角色之死是否既不推动主线也无偿还爽点？ | 命中即违规 |

（第七项为工程冗余：LLM 常为"深刻感"杀角色，与网文读者契约冲突。）

### 2.2 麦基负面节拍的网文降档规则（三条）

麦基要求场景价值负向转变、对抗力量压倒主角（战败狗）——连载网文按下表降档执行：

**a. 战败狗每卷重判＋品类豁免表**

| 品类 | 战败狗适用 | 压力改写方式 |
|------|-----------|--------------|
| 无敌流/碾压流 | 豁免 | 压力不打在胜负上，改写为"如何有趣地碾压"：信息差、立场错位、演出效果 |
| 常规升级流 | 每卷重判（对接 K-CONFLICT-003 长篇再入规则、K-WORLD-022 锚定表） | 对抗总和 > 主角当前战力，卷内成立即可 |
| 谋略流/悬疑骨架 | 全额适用 | 按原教旨执行 |

**b. 惨败节拍配额**：惨败 = 主角损失核心资源/位阶/重要关系且当场无还手。**单卷 ≤1 次，且 ≤2 章内开始翻转或止损反击**；超配额或翻转超窗 = 违规。

**c. 同向递进合法**：场景价值允许 + → ++（幅度或维度位移），不强制正负翻转；整场零位移才违规（对接 K-STRUCT-010）。压抑段的"负"优先用小负（受阻、付代价），不轻易动用惨败。

### 2.3 操作步骤

1. P2：扫粗纲各卷压抑段，逐段标注预计章数与补偿爽点位置，过 2.1 表。
2. P5：为每个负面节拍配对 `payoff_entries` 条目（对接 K-STRUCT-020）；惨败节拍登记翻转章号。
3. P6/critic：按 2.1 判定问句扫已写章，命中 → repair 改写，或在红线窗口内补偿还章。

### 2.4 可判定标准

| 检查项 | 通过判据 |
|--------|----------|
| 憋屈窗口 | 无连续 >2 章未翻盘的下风段 |
| 惨败配额 | 单卷惨败 ≤1 次且 ≤2 章内翻转 |
| 毒点扫描 | 七问全"否"，或已按红线值处理 |
| 补偿配对 | 每个压抑段可指认补偿爽点（章号或 payoff 条目） |

### 2.5 示例

《斗破苍穹》开局退婚是重压抑，但受辱当场立下"三十年河东"宣言与三年之约——憋屈不过夜、压抑必挂偿还时间表的教科书示范。《庆余年》范闲牛栏街遇刺近乎惨败，随后数章内反杀追凶、朝堂问责连环翻转——惨败节拍在 ≤2 章窗口内翻转的标准用法。

## 三、防抄袭与融梗边界

**适用场景**：P2 设定设计自查（route=web 白名单已含本块）；P4 细纲名场面设计时按需参考；P6 critic 轮抽检金句与名场面；diagnose「撞梗/抄袭疑虑」。

**输入**：本书专名词表、参考作品清单（对比填充法使用时）、待查桥段或正文。

### 3.1 三级判定表

| 层级 | 对象 | 边界 | 处置 |
|------|------|------|------|
| 设定级 | 类型公共资源：修炼位阶概念、系统面板、克苏鲁式神话框架、副本/位面 | **可借鉴**：概念可用，命名与组合必须原创 | 沿用他书专名 → 按专名撞车处理 |
| 桥段级 | 具体情节组合：退婚开局、当众打脸、夺舍重生等名场面 | **须变形 ≥2 要素**（五要素：人物关系/动机/场景/手段/结果） | 变形 <2 要素 = 违规重排 |
| 文字级 | 句段表达 | **零容忍**：连续 ≥12 字非公共表达复现即违规（成语、俗语、公共引语豁免） | 必改写 |

### 3.2 LLM 语料复现自查（三项）

LLM 的风险不是"想抄"，而是训练语料**无感复现**——顺手写出的专名、金句、桥段可能是别人的。逐项自查：

1. **专名撞车 rg 词表**：开书建立本书专名词表（人名/功法/组织/地名/金手指名）；每个专名做检索比对——有本地语料库用 `rg "专名"` 扫描，无语料库用站内与全网检索"专名＋小说"；与知名作品核心专名同名 = 违规必改（如新书宗门起名"青云门"即撞《诛仙》核心专名）；每卷新增专名入表复查。
2. **金句复现警戒**：章尾钩句、宣言句、道理句是语料复现高危区；每章抽 3 句最"漂亮"的句子检索比对，命中连续 ≥12 字即按文字级处理。
3. **名场面还原度三问**：① 读者能否直接叫出"这是某书某场面"？② 把本书专名换回原作专名是否毫不违和？③ 关键道具、标志台词、动作设计是否 ≥2 项与原作相同？——任一"是"，按桥段级变形 ≥2 要素后重写。

### 3.3 对比填充法安全使用界

对比填充法（提取成熟作品同类型卷的元素结构再自填内容，方法见 K-CONCEPT-005 所在文件附录）的三条边界：**结构可学**——"入城→结识权贵→卷入夺嫡→扬名"这类功能序列可提取；**表达必须重写**——任何句段不得照搬；**专名必须原创**——人名、功法、组织零沿用。填充完成后按 3.1 桥段级复检：与参考卷同位置事件须 ≥2 要素不同。

### 3.4 可判定标准

| 检查项 | 通过判据 |
|--------|----------|
| 专名词表 | 词表存在；卷末对账"本卷新增专名均已过查" |
| 金句抽检 | 每章 3 句高亮句无连续 ≥12 字复现 |
| 桥段变形 | 可指认的借鉴桥段均列得出 ≥2 处要素变形 |
| 填充复检 | 对比填充产物与参考卷同位事件 ≥2 要素不同 |

### 3.5 示例

《诡秘之主》借克苏鲁神话框架（不可名状存在、疯狂与污染代价）属设定级公共资源借鉴，而序列 0–9 途径体系、塔罗会、自创神系命名全部原创——概念同源、体系与专名全原创的合法示范。反面（泛化）：把某知名作品"退婚受辱→当众立誓→三年后打脸"的桥段照搬，只改人名地名，五要素一个未动——桥段级违规，须重排。
