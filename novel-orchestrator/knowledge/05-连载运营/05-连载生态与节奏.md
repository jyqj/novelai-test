## 一、免费流读者模型与短剧化节奏

**适用场景**：P1 立意与开篇设计、P2/P3 大纲期节奏预埋、P5 前 30 章章纲校验；diagnose「开篇留不住/前 10 章流失/数据断崖」。背景：免费阅读渠道主导增量读者，推荐算法按追读率分发——本块只给创作侧约束，不承诺任何平台的具体数据口径。

### 1.1 三道弃读门

| 门 | 读者行为 | 创作要求 |
|----|----------|----------|
| 前 3 秒 | 扫书名/封面/第一屏 | 高概念一屏可感（K-CONCEPT-001）：书名与首屏点明差异化卖点；首屏禁世界观名词堆砌 |
| 前 300 字 | 划两屏定去留 | 反预期信号或冲突已在场（K-WRITE-020 开头三段钩同规格）；禁背景倾倒 |
| 前 3 章 | 决定是否入库追读 | 主线引爆 ≤第 3 章（K-STRUCT-008 网文换算层）；每章 ≥1 小爽（K-STRUCT-020）；章末钩全勤 |

### 1.2 短剧化 = 大纲期动作（操作步骤）

短剧化叙事的正确落点在 P2/P3 大纲期嵌入高冲突密度与强反转，**不是**正文期临时加猛料：

1. 排大纲时按「单章即一集」检验：每章能否用一句「冲突—反转」句式概括；概括不出的章合并或重排。
2. 高冲突密度前置：卷级激励事件落在卷首 10% 以内。
3. 强反转预算：每 10 章 ≥1 次预期颠覆（reversal 型爽点，预埋纪律见 K-STRUCT-020——禁无预埋硬反转）。
4. 边界：短剧化管**密度与拍点**，不等于砍铺垫——每段铺垫须挂在一个已开承诺上（K-STRUCT-021 期待账户），挂不上的铺垫延后。

### 1.3 追读率对创作的三条约束

1. **章末弃读 > 章中弃读**：章尾钩纪律全勤（K-WRITE-020 §3.4），弱钩章连续 ≤1。
2. **断更即断推**：节奏可持续性优先于单章雕花——字数稳定在 2000–4500 默认档，不为单章加长牺牲更新稳定。
3. **跳读要能接上**：读者跳读后关键信息须有一次自然重锚（依托 recap_state 维护的现状；正文内重锚 ≤1 句，防复述型水，对照 K-WRITE-021）。

### 1.4 免费流 vs 付费流策略差异表

| 维度 | 免费流 | 付费流 |
|------|--------|--------|
| 分发逻辑 | 算法推荐，追读率驱动 | 书城榜单 + 订阅转化 |
| 生死线 | 前 3 章去留 | 上架章订阅转化 |
| 爽点节律 | 小爽高频前置（3 章窗口刚性） | 可稍缓，大爽对齐付费节点 |
| 铺垫容忍 | 低：铺垫须挂已开承诺 | 中：可养长线 |
| 章末钩 | 全勤刚性 | 强烈建议 |
| 题材倾向 | 强类型信号、即时代入 | 容忍慢热与复杂设定 |

双轨发行（`flags.dual_track`）按更严的免费流约束执行。

### 1.5 示例（泛化）

赘婿反转文前三章：第 1 章开场即当众羞辱 + 主角亮出第一层反差（300 字内），章末危机钩；第 2 章兑现一次 dopamine 小爽 + 开新承诺（神秘岳母似乎知道他的底细）；第 3 章主线引爆（家族清算令下达=激励事件）+ 首个 reversal（白天羞辱他的人晚上登门跪求）。三道门全过，期待账户余额 3。

## 二、卷级 0–23 嵌套法

**适用场景**：模式 B（route=web 分卷长连载）下 P2 书级脊骨规划与 P3 每卷序列图展开；卷末→新卷交接操作；diagnose「卷间疲软/新卷开头掉量/越写越散」。

### 2.1 两层结构

1. **书级**：PlotSpine 24 节点（0–23）保留为规划资产——模式 B 下每节点≈一卷的主题弧，由 `volume_map: {volume_id, theme, node_range}` 建立映射（一卷可对应一个或相邻两三个节点）；书级锚点为 soft（缺失仅 warning，见 `templates/plot-spine.md` 模式 B 注记）。
2. **卷内**：每卷一个 `seqmap_v{n}`，卷内完整走 0–23（含卷级序列 0 Hook）；锚点 gate 以**卷内**为强制（P3 gate）。
3. 序列引用一律复合键 `{volume_id, sequence_index}`（速记 `v3:s12`）——只说「第 12 序列」不带卷号即非法引用。

### 2.2 卷级价值接力

1. 每卷确定卷级价值轴（本卷主冲突在哪条价值上摆动，如「信任：孤立⇄有袍泽」）。
2. **卷 N 的结束值 == 卷 N+1 的起始值**：接力不断档、不跳档；校验落在 volume_checkpoint 卷报告——写明「本卷结束值」「下卷起始值」两句，不等则补桥（卷末尾声或新卷序列 0）。
3. 书级 24 节点的价值走向是各卷接力的外包络：卷内可有完整起伏，但卷末落点须踩在对应书级节点要求的方向上。

### 2.3 卷末大高潮 → 新卷重置期待（操作步骤）

1. 卷末（卷内序列 19–23）：清算卷级 Boss、兑现本卷大爽、收束卷内 Thread（`must_not_drop` 与跨卷 waypoint 线除外）。
2. 高潮章至卷末尾声之间**开出 ≥1 个指向新卷的新承诺**：下任反派挂牌（K-CHAR-012）、新地图凭证、身世新层三选一起步。
3. 新卷序列 0–1（约卷首 3 章）：**降档重启**——烈度降档、短暂日常回归（波段模型「卷间重置」，见冲突文件速查表「冲突递进公式」注记），但期待账户不清零（K-STRUCT-021 余额 ≥2）。
4. 新卷激励事件 ≤卷首 10%（K-STRUCT-008 换算层），且须与卷末埋下的新承诺**同源**——不许另起炉灶让上卷的钩子作废。
5. 流程纪律：volume_checkpoint 卷报告 + 用户确认后才 `open_next_volume`（`runtime/web-serial-playbook.md` §9）。

### 2.4 可判定标准

| 检查项 | 通过判据 |
|--------|----------|
| 价值接力 | 卷 N `value_end` == 卷 N+1 `value_start`（卷报告两句可直接比对） |
| 期待不清零 | 卷末高潮后未兑现承诺 ≥2 个，其中 ≥1 个指向新卷 |
| 重置深度 | 新卷前 3 章无卷级 Boss 正面大战（降档期），但每章仍有小爽 |
| 嵌套完整 | 每卷 seqmap 0–23 齐 + 卷内必保锚点齐；书级 `node_range` 无缝覆盖该卷 |
| 引爆时点 | 新卷激励事件落位 ≤卷内 s2（约前 10%） |

### 2.5 示例（泛化）

六卷修行文，书级 24 节点分包进 `volume_map`（卷 1=节点 0–5「离乡」……卷 3=节点 12「中间点：认知颠覆」……）。卷 2（节点 6–8）价值轴「信任：孤立→有袍泽」：卷末大高潮破山门获胜、但袍泽阵亡——结束值=「带着代价的信任」；高潮章埋新承诺（阵亡者遗物指向北境禁地），下任 Boss 本卷已两次预埋。卷 3 起始值=「带着代价的信任」（接力相等），前 3 章降档处理后事、小爽不断（葬礼上识破吊唁者伪装=reveal），第 3 章禁地开启=新卷引爆，与遗物承诺同源。

### 2.6 卷级语义降档表（0–23 节点卷级重解释速查）

卷内 seqmap 沿用 K-STRUCT-003 节点名，但**「重生」「保护壳」「彻底告别自我」语义仅卷一有效**——从第 2 卷起各节点按下表卷级语义执行；书级 24 节点经 `volume_map` 的映射不受本表影响。

| 节点 | 卷级语义（第 2 卷起） |
|------|----------------------|
| 0 Hook | 卷首钩：承接上卷末新承诺（同源，禁另起炉灶） |

| 2 引发事件 | 卷级激励事件（≤卷首 10%） |
| 3 历险召唤 | 本卷新挑战适应期（删「抗拒召唤」心理语义） |
| 4 开始上路 | 进入本卷新舞台/新战线 |
| 5 挣扎与陷阱 | 本卷对抗力量首轮交手试探 |
| 6 陷阱启动 | 卷内惊人意外#1：局势升格 |
| 7 欢迎登船 | 本卷长期目标与计划成形 |

| 16 战胜自己 | 认知升级或立场揭示（弧光为可选件） |
| 17 做好准备 | 本卷 All in：筹码押上桌 |
