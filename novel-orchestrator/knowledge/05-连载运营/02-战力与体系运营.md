## 一、战力锚定表与卷级增幅预算

**适用场景**：P2/P4 建 `domain=power` 的 WorldRule 时建锚定表；每卷卷初定增幅预算、卷末（volume_checkpoint）对账；diagnose「战力崩/同阶忽强忽弱/主角强度失控」。

### 1.1 操作步骤

1. **建锚定表**：每个境界/位阶一行，四列齐——

| 境界 | 稳胜区间 | 五五开区间 | 必败区间 | 标尺人物 |
|------|----------|------------|----------|----------|
| [第 N 阶] | [低两阶及以下] | [同阶 ±1 小层] | [高一大阶及以上] | [读者熟悉的具名角色] |

   区间用**境界差**表述而非形容词；标尺人物是该档位的「活标尺」，读者用他校准强度感。
2. 锚定表登记进 WorldRule（`domain=power`）的战力锚定表小节（`power_anchors`，正文区附表，见 `templates/world-setting.md` §2.3）；影响情节的行升 `canon`。
3. **卷初定增幅预算**：本卷主角升几阶 + 获得哪些非境界增量（装备/招式/信息/势力），一并写入卷规划；默认预算 ≤1 大阶/卷，体系另有约定须 Decision 留痕。
4. **写作中对账**：每场战斗写前查表，本场对手落在哪个区间；结果要跨区间（必败区打赢）→ 走 K-WORLD-023 越阶配额，不许静默跨区。
5. **卷末对账**（volume_checkpoint）：实际增幅 vs 预算写进卷报告「战力变化」；`recap_state` 的主角境界字段与锚定表当前行同步；超预算 → 下卷预算扣减或安排代价回收。
6. **跨卷标尺更替**：主角越过某标尺人物后该行失效——卷末为该档换入新标尺（新出场的更高层角色），旧标尺行保留「已越过」备注 ≤1 卷，供读者对比成长幅度。

### 1.2 可判定标准

| 检查项 | 通过判据 |
|--------|----------|
| 锚定表存在 | `domain=power` 的 WorldRule 含锚定表，每境界三区间 + 标尺齐 |
| 标尺有效 | 主角当前境界 ±2 阶的每个档位都有仍在场的标尺人物 |
| 增幅预算 | 卷初有预算记录；卷末对账偏差 ≤1 小层，超出须 Decision 留痕 |
| 战斗合规 | 任一战斗结果可在表内区间解释，或有 K-WORLD-023 配额登记 |
| recap 同步 | `recap_state` 境界字段 == 锚定表当前行 |

### 1.3 示例（泛化）

修行文四大境（淬体/凝罡/破窍/化神）：卷 2 预算「凝罡中层 → 凝罡巅峰」。卷中主角得秘宝提前摸到破窍门槛——卷末对账超预算半阶，处置：下卷预算改为「稳固境界、无大阶提升」，并以旧伤复发做代价回收。标尺更替：卷 1 用「武馆总教头」标定凝罡档，卷 3 主角越过后换「郡城巡查使」标定破窍档，总教头行保留一卷备注「已越过」。

## 二、越阶战斗合法性配额

**适用场景**：P4/P5 计划越阶战、P6 写前合法性自查；diagnose「越阶胜廉价/读者不信服/主角光环」。越阶=战斗结果落在锚定表（K-WORLD-022）的必败区间却获胜。

### 2.1 合法性三要素（缺一即不合法）

1. **预埋代价**：获胜要消耗的资源/伤势/后遗症，**战前已埋、战后兑现**——不许战后免单，不许「重伤」两章后无痕。
2. **环境或信息差**：地利、阵法、对手情报缺口、第三方介入等非纯战力变量，**开战前已向读者展示**（战中才冒出=作者送的）。
3. **一次性资源**：底牌（符/丹/禁术/人情）用一次少一次，用后即时减记，禁止无限复用。

### 2.2 配额

| 配额项 | 上限 |
|--------|------|
| 每卷越阶胜 | ≤2 场 |
| 其中「顿悟破局」（临阵突破/灵光一现，K-WORLD-014 顿悟模式） | ≤1 场 |
| 同一手段（同一底牌/同一环境套路）全书重复 | ≤2 次（K-STRUCT-012 回报递减） |

越阶**败**不占配额——输给高阶反而是修复强度感的手段。

### 2.3 违规检测清单

| 信号 | 判定 |
|------|------|
| 战后主角无可见损耗 | 违规（要素 1 缺） |
| 越阶变量战中才首次出现 | 违规（要素 2 缺） |
| 底牌用完不减记、下次照用 | 违规（要素 3 缺） |
| 本卷第 3 场越阶胜 | 违规（配额超；改写为败/平/借力） |
| 连续两卷都靠临阵顿悟翻盘 | 违规（顿悟配额 + 同型重复双杀） |

### 2.4 操作步骤

1. 计划期在 ChapterPlan 备注越阶场次，标注三要素各自的预埋落点章号。
2. 写前自查三要素齐备 + 查本卷配额台账（卷报告累计）。
3. 写后登记：消耗的一次性资源从 `recap_state` 持有物中减记，新欠的代价（人情/后遗症）登 Thread 或 `facts`。

### 2.5 示例（泛化）

主角（凝罡）胜破窍执事：战前两章埋「借来的一次性雷符（欠宗门人情）」+「执事旧伤惧火」的情报 + 「祠堂地形狭窄、大范围术法施展不开」；战后雷符除名、人情成新 Thread、主角重伤休养两章。本卷越阶配额记 1/2，顿悟 0/1。

## 三、金手指边际递减设计

**适用场景**：P1/P2 设计金手指（系统/外挂/特殊天赋/重生信息差）时预设衰减曲线；连载中期 diagnose「金手指万能化/读者觉得无脑/主角自身存在感稀薄」。

### 3.1 效用衰减曲线（三段）

| 阶段 | 金手指作用 | 叙事功能 |
|------|-----------|----------|
| 前期（约首卷） | 碾压级：直接解决战斗/资源问题 | 建立爽感与差异化卖点 |
| 中期 | 辅助级：给效率/信息优势，不再直接定胜负 | 让主角自身成长接管胜负归因 |
| 后期 | 身份/信息价值：金手指的来历与归属本身成为主线 | 转化为世界观级悬念与各方争夺的筹码 |

递减的正确做法是**问题升维**（对手与难题超出金手指直接解决的量级），不是数值削弱或临时失灵。

### 3.2 操作步骤

1. 设计期写下三段曲线各自的「能做/不能做」清单，登记入 WorldRule（`power` 或 `core` 域）。
2. 每卷卷初标注金手指当前段位（随卷报告滚动）。
3. **递减前 ≥1 卷铺垫替代成长轴**：主角自身实力/势力/人脉/心智四选一起步——递减发生时替代轴须已可见运转，否则读者体验为「主角变弱了」。
4. 后期把金手指的存在变成情节：来历揭示挂 mystery Thread、被觊觎成为新冲突源、隐藏代价显形。

### 3.3 万能化症状与修法

| 症状 | 判据 | 修法 |
|------|------|------|
| 万能钥匙 | 连续 2 卷所有关键难题都由金手指直接解决 | 下一难题设计为金手指**原理性**无效（非临时失灵） |
| 无代价 | 使用从不消耗、从无反噬 | 补代价机制（对照 K-WORLD-013）；已发布章不回改，走 retcon_note 向前兼容 |
| 无来历悬念 | 全书从未有人追问其来源 | 为其开幕后引线（K-CONCEPT-011） |
| 挤占人物 | 读者只记得挂、不记得人 | 安排一卷「金手指低效期」，让人物弧光（K-CHAR-005）接管叙事 |

### 3.4 示例（泛化）

鉴宝系统流：前期系统直接报真伪与估价（碾压捡漏）；中期只提示「有异常」，须主角自己的眼力验证——卷 3 起主角拜师学鉴定即替代成长轴，提前一卷铺入；后期系统来源指向失踪的师祖与一桩三十年旧案（mystery Thread），鉴定能力已内化为主角本领，系统本身成为各方争夺的身份秘密。
